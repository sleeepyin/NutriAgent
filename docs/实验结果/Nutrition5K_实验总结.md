# Nutrition5K 实验总结（MM-CFA 项目）

> 文档目的：汇总本项目（MM-CFA，多模态共形食物分析）在 Nutrition5K 数据集上完成的全部实验，解释每个实验的含义、结果与解读方式。面向初次接触本项目的读者。
>
> 依据来源：`Nutri_0811/paper_cn.md`（论文全文）、`README.md`（复现说明）、`Nutri_0811/*.py`（实验脚本）。

---

## 0. 项目目标

拍一张食物照片，自动估计：

1. 这盘菜**有多重**（重量估计）；
2. 含多少**热量 / 脂肪 / 碳水 / 蛋白质**（营养素估计）；
3. 并给每个预测配一个**预测区间**（如"180~220g，90% 把握"），用于临床营养监测等安全关键场景。

---

## 1. 名词表（先读这个）

| 名词 | 含义 |
|---|---|
| **Nutrition5K** | Google 发布的公开食物数据集。本项目使用其中 3,260 张带真实重量标签的 RGB-D 食物裁剪图；营养素标签来自菜品元数据（5,006 道菜品，经 dish_id 映射）。拍摄条件：固定俯视 RealSense 深度相机、餐厅菜品。 |
| **RGB-D / 4 通道** | 普通 RGB 三通道 + 一个深度通道（每像素记录离相机距离），拼成 4 通道输入。 |
| **点估计** | 模型输出的单个数字（如"200g"）。 |
| **预测区间** | 模型输出的范围（如 [180g, 220g]）。 |
| **共形预测（CP）** | 有数学保证的造区间框架：用校准集统计"模型通常错多少"，给新预测加误差余量，保证长期覆盖率 ≥ 1−α。本项目 α=0.10，目标覆盖率 90%。 |
| **校准集** | 一部分模型没训练过的数据，专门用来定区间宽度。 |
| **覆盖率** | 测试集中真实值落入区间的比例。目标 ≥90%；低了是"说大话"，太高是区间太宽没用。 |
| **区间宽度** | 区间平均长度（克）。覆盖率达标前提下越窄越好。 |
| **Winkler 分数** | 区间宽度 + 未覆盖惩罚，越小越好；防止靠无限加宽刷覆盖率。 |
| **MAE / PMAE / WAPE** | MAE：平均误差（克）；PMAE：平均相对误差百分比（200g 错 20g = 10%）；WAPE：总误差÷总重量（大菜权重高）。均越小越好。 |
| **R²** | 模型解释数据波动的比例，1.0 完美，0 等于猜均值。 |
| **10 次随机试验（50/20/30）** | 50% 训练 / 20% 校准 / 30% 测试，10 个随机种子重复，报告均值±标准差。 |
| **严格 hold-out** | 一次性固定划分（2,608 训练 / 652 测试），测试集全程不碰。比 10 次试验更保守、成绩更差但更可信。 |
| **配对 t 检验 / Cohen's d** | 判断"A 比 B 好"是真差异还是运气的统计方法。 |


所有实验统一协议：α=0.10；10 次随机划分 + 配对 t 检验统计验证；营养素区间实验使用严格 hold-out。

## 3. 实验 1：重量点估计基预测器

**做什么**：ResNet18 + EfficientNet-B0 双模型集成，均改为 4 通道 RGB-D 输入（224×224），log-MSE 损失，ImageNet 预训练迁移，输出取两模型平均。

**结果**：

| 协议 | 指标 |
|---|---|
| 10 次随机试验（开发口径） | MAPE = 9.44% ± 1.05%，MAE = 18.8g。不作为正文主数字 |
| 严格 hold-out | 4 通道 MAPE = 22.0%（≥100g 子集 18.4%）。更早一版集成 MAPE = 31.24%。3 通道 MAPE = 31.4% |

**怎么看**：9.44% 已接近单张照片的信息天花板（密度、含水量等信息照片里根本没有，见 §6 论证）。后续区间实验建立在一个高质量点估计之上。hold-out 成绩更差是正常现象——测试菜品模型从未见过。

## 4. 实验 2：7 种共形方法造重量区间（核心实验，§5.1）

**7 种方法是什么**：

| 方法 | 原理（人话） |
|---|---|
| **Split** | 校准集误差取 90% 分位（如 78g），所有预测统一 ±78g。区间一样宽。 |
| **Normalized** | 用相对误差：小菜大菜都 ±x%，大菜区间自然更宽。 |
| **Mondrian** | 按重量分 4 箱，每箱单独算分位数。 |
| **AEC** | 把多种方法的区间加权混合，Dirichlet 采样 5000 组权重找"覆盖够且最窄"的。全局一组权重。 |
| **AEC-S（本文核心创新）** | AEC 升级版：5 个重量段各学一组权重 + 贝叶斯收缩（τ=30）防止小样本段过拟合。 |
| **MLNS** | 训练梯度提升模型预测"这次大概错多少"来定宽度。基预测器太准（误差≈噪声）时失效。 |
| **MTC** | 重量+4 营养素联合造区间，Holm-Bonferroni 校正。区间极宽。 |

**结果（论文表 1，10 次试验）**：

| 方法 | 覆盖率 | 宽度 | Winkler | 达标 ≥90% |
|---|---|---|---|---|
| Split | 90.1% | 78g | 213 | ✅ |
| Normalized | 90.3% | 94g | 191 | ✅ |
| Mondrian | 90.3% | 80g | 187 | ✅ |
| AEC | 90.3% | 77g | 181 | ✅ |
| **AEC-S** | **91.0%** | **76g** | **182** | ✅ |
| MLNS | 81.8% | 77g | 192 | ❌ |
| MTC | 98.0% | 315g | 352 | ✅ 但不可用 |

**怎么看**：

1. 先筛覆盖率：MLNS 81.8% 出局（说 90% 实际只有 82%，安全场景不可用）。
2. 达标者中比宽度：AEC-S 76g 最窄，且 10 次试验稳定、经 t 检验显著。
3. MTC 98% 覆盖但 315g 宽，Winkler 352 全场最差——覆盖率不是越高越好。
4. AEC-S vs AEC（91.0%/76g vs 90.3%/77g）证明"分段学权重"优于"全局一组权重"——这是论文核心论点。

> ⚠️ **泄漏警告（重要）**：表 1 中 **AEC 和 AEC-S 两行是带评估泄漏的结果**——它们的全局权重是在测试集上搜索的（见 §9(a) 与 §9(e)）。Split / Normalized / Mondrian / MLNS / MTC 五行不受影响（纯校准集方法，不涉及权重搜索）。AEC-S 的诚实版数字为 **90.4% / 74g / Winkler 181**（表 8），泄漏仅虚增约 3g 宽度，不改变"AEC-S 最优"的结论。论文摘要、表 1、结论引用的是泄漏版数字，这是本文档已标注、后续重写论文时需要修正的报告规范问题（详见 §9(e)）。

## 5. 实验 3：逐重量段分析（§5.2–5.3）

**做什么**：按真实重量切 5 段，看 AEC-S 学到的权重配方与逐段覆盖率。

**结果（表 2，各段主导方法）**：

| 重量段 | 主导方法（权重） | 原因 |
|---|---|---|
| 0–50g | Mondrian 67% | 小样本最受益于分箱单独校准 |
| 50–100g | Normalized 40% | 相对误差在此段最规律 |
| 100–200g / 200–500g | Split 40% / 85% | 数据最多最稳，恒定宽度就够用 |
| 500g+ | MLNS 53% | 尾部稀疏高方差，学习特征反而有用 |

**逐段覆盖率（表 3/4）**：最难的 500g+ 段从 Split 的 71.8% 提升到 **84.3%**（+12.5pp）；0–50g 段 84.2% 且宽度仅 11g。

**怎么看**：各段权重差异巨大（中段 Split 占 85%，轻食段 Mondrian 占 67%），直接证明"全局单一权重是次优的"，分层设计合理。

## 6. 实验 4：营养素点估计（§5.4）

**背景**：营养素 = 重量 × 密度（每克含量）。对比 4 种方法 × 4 种营养素。

| 方法 | 含义 |
|---|---|
| **Oracle（先知）** | 用真实密度作弊，只让重量有误差 → 理论上限 |
| **直接回归（本文）** | 深度模型从图像预测密度 × 预测重量 |
| **k-NN 检索** | 特征空间找 5 个最近邻平均其密度 |
| **重量→营养素** | 只用预测重量线性外推，不看图像内容 |

**结果（表 5，热量为例）**：

| 方法 | 热量 PMAE | 解读 |
|---|---|---|
| Oracle | 7.5% | 上限，证明"重量×密度"公式正确 |
| **直接回归** | **12.6%** | 比朴素基线提升 63% |
| k-NN | 24.6% | 检索不如学习 |
| 重量→营养素 | 34.4% | 只看重量最差 |

其他营养素（直接回归 PMAE）：脂肪 24.3%、碳水 25.3%、蛋白质 22.4%（R²=0.864）。

**怎么看**：

- Oracle(7.5%) 与直接回归(12.6%) 的差 = 密度预测误差 → **营养素误差的瓶颈在密度，不在重量**（全文最重要诊断之一）。
- 碳水最难：米饭（高密度）vs 沙拉（低密度）密度变化大。
- Oracle 是作弊上限，真实方法不可能超过它。

## 7. 实验 5：消融实验（§5.5）

**做什么**：逐个加组件，证明每个设计有独立贡献。

**结果（表 6）**：Split 78g → +Normalized 94g → +Mondrian 80g → +AEC 全局 77g → **+AEC-S 分层 76g（覆盖率 90.3%→91.0%）**。

**怎么看**：AEC→AEC-S 这一步宽度 −1g、覆盖 +0.7pp，证明"分层"本身有贡献，改进不是堆料。

## 8. 实验 6：营养素共形区间 AEC-S2m-N（§5.6）

**做什么**：给 4 种营养素各造 90% 区间。5 种候选信号：

- **Split**：绝对误差分位；**Norm**：相对误差分位；**LogSplit**：log 空间分位；
- **Propagate**：重量区间 × 密度点估计直接传播；
- **MondrianW**：按重量分段各自校准。

组合配方与重量侧相同（分段 + Dirichlet 搜权重 + 贝叶斯收缩 τ=30 + 逐段重标定）。**严格 hold-out 协议**（2,608 训练 / 652 测试对半分校准与评估）。

**结果（表 7）**：

| 营养素 | 覆盖率 | 相对宽度 |
|---|---|---|
| 热量 | 90.5% | 95.6% |
| 脂肪 | 90.6% | 166.3% |
| 碳水 | 89.7% | 152.1% |
| 蛋白质 | 90.5% | 151.8% |

综合归一化 Winkler = **2.42**，优于最强单候选 MondrianW（2.50）和 Split（2.74）。

**怎么看**：

- 覆盖率全部落在 89.7–90.6%，贴住 90% 目标：既没漏也没浪费。
- "相对宽度 166%"指脂肪区间宽≈预测值的 1.66 倍——看着宽，但脂肪点估计 PMAE 本就 36.5%，区间如实反映不确定性，**诚实比漂亮重要**。
- 关键诊断：**Propagate 单独用脂肪覆盖率仅 63.7%**（严重欠覆盖）——它只传播了重量的不确定性，没算密度的。再次证明密度误差主导营养素不确定性。
- LogSplit 在预测值近 0 时爆炸（宽度 359%），被集成自动压低权重——集成能容错坏候选。
- 重标定必要：没有它脂肪覆盖率降至 88.6%。

## 9. 实验 7：诚实性实验（§5.7）

不追求更好数字，而是主动找自己方法里的坑，共 4 件事：

### (a) 修复评估泄漏（表 8）

原版 AEC-S 优化全局权重时偷看了测试数据。修复后（权重只在校准集上学）：90.4% / 74g / Winkler 181——**泄漏只值约 3g**，方法本身扎实。加重标定后得两个最强变体：

| 变体 | 覆盖率 | 宽度 | Winkler |
|---|---|---|---|
| AEC-S（原始，有泄漏） | 91.1% | 77g | 183 |
| AEC-S（诚实） | 90.4% | 74g | 181 |
| AEC-S2c（诚实+全局重标定） | 89.9% | 69g | 172 |
| AEC-S2m（诚实+逐段重标定） | 90.4% | 76g | **171** |

### (b) Double-dipping 失败模式（命题 1）

在**同一批**校准数据上既学集成权重又算共形分位数 → 权重过拟合 → 分位数被低估 → 区间系统性偏窄（反保守）。候选加得越多欠覆盖越严重：5 候选欠 0.3pp → 7 候选欠 0.6pp → 7 候选+营养素分层欠 1.0pp，与理论预测完全一致。两阶段校准（权重、分位数分用两半数据）能恢复覆盖但区间变宽，**仍不如 5 候选单阶段配方（2.42）**。

教训："加更多候选信号"表面让区间更窄，实际是骗自己。

### (c) CQR 基线（表 9）

共形化分位数回归（直接输出 10%/50%/90% 分位数）：原始区间覆盖率仅 **34.7%**（名义 80%）——2,608 张图不够学条件分布；修到能用（90.5%）后 nWinkler 2.55，仍输本文 2.42（−5.7%）。

教训：流行方法在小数据上未必好；基于点估计残差的共形校准样本效率更高。

### (d) 加权共形基线（表 9）

为协变量偏移设计的现代方法。域内校准/测试同分布时学不到偏移，退化为普通共形（89.2% / nWinkler 2.54，被 AEC-S2m-5W 支配）。

作用：防御性实验 + 划清方法适用边界。

### (e) 泄漏影响范围与报告规范讨论（本文档补充，非论文原有内容）

**泄漏的技术根源**：[conformal_deep_experiment_final.py](file:///c:/Users/Triste/Desktop/NutriAgent-main/Nutri_0811/conformal_deep_experiment_final.py) 中全局权重的搜索直接使用了测试集数据（`w_global, _ = _dirichlet_search(test_lowers, test_uppers, y_test, target)`），导致 AEC 与 AEC-S 在表 1 中的数字偏乐观。[aec_s_v2_experiment.py](file:///c:/Users/Triste/Desktop/NutriAgent-main/Nutri_0811/aec_s_v2_experiment.py) 则同时实现了泄漏版（`AEC-S-leak`）与诚实版（`AEC-S-honest`），用于量化泄漏幅度。

**各实验受泄漏影响一览**：

| 实验 / 表格 | 协议 | 是否受泄漏影响 | 说明 |
|---|---|---|---|
| 表 1：Split / Normalized / Mondrian / MLNS / MTC | 10 次 50/20/30 | ✅ 无 | 纯校准集方法，不涉及权重搜索 |
| 表 1：**AEC** | 10 次 50/20/30 | ❌ 有 | 直接使用在测试集上搜索的全局权重 |
| 表 1：**AEC-S** | 10 次 50/20/30 | ❌ 有 | 分段权重在校准集学，但贝叶斯收缩的**全局先验**来自测试集 |
| 表 2–4（逐段分析） | 同表 1 | ❌ 有 | 派生自表 1 的 AEC-S 结果 |
| 表 5（营养素点估计） | 10 次 50/20/30 | ✅ 无 | 点估计，不涉及共形校准 |
| 表 6（消融） | 同表 1 | ❌ AEC/AEC-S 行有 | 其余行干净 |
| **表 7（营养素共形 AEC-S2m-N）** | **严格 hold-out** | ✅ 无 | 测试集全程不碰，从头干净 |
| 表 8（诚实变体） | hold-out 校准/评估 | 同时展示两版 | 泄漏版 91.1%/77g vs 诚实版 90.4%/74g |
| 表 9（CQR / 加权共形） | hold-out | ✅ 无 | 独立方法 |

**报告规范问题**：从严格学术规范角度，论文的主要结果（摘要、表 1、结论）应当使用诚实版本报告。论文实际做法是：

- 摘要、表 1、结论引用**泄漏版**数字（AEC-S 91.0% / 76g）；
- 诚实版数字（90.4% / 74g）放在 §5.7 作为修正分析呈现。

这是一种**次优但可接受的妥协**：泄漏幅度小（约 3g）、所有结论在诚实协议下依然成立、最终推荐变体（AEC-S2m，90.4% / 76g / Winkler 171）本身是诚实的、营养素共形结果（表 7）从头干净。但缺陷明显：

1. 只读摘要的读者拿到的是偏高数字；
2. 主结果表与"有泄漏"事实不匹配；
3. 审稿人完全有理由要求用修正协议重跑表 1。

**后续重写计划（TODO）**：重写论文全文时，主结果（摘要、表 1、结论）应改用诚实协议数字——AEC-S 诚实版 90.4% / 74g / Winkler 181，并以 AEC-S2m（90.4% / 76g / Winkler 171）作为重量侧最终推荐方法；泄漏版数字仅保留在 §5.7 诚实性分析中作为对照。

## 10. 附加实验：DINOv2 现代骨干消融

**做什么**：把 ResNet18 换成自监督强骨干 DINOv2-small 重训重量模型。

**结果**：PMAE **31.3%** ≈ ResNet18 三通道版（31.4%），远不如四通道版（22.0%）。

**怎么看**：换更强架构精度零提升 → **瓶颈不在模型容量，而在单张照片缺少密度/尺度信息**。突破天花板要加信息（深度、参照物、问用户），不是换大模型。这是后续 Agent 方向（主动信息获取）的动机。

## 11. 一页总结

| 实验 | 核心数字 | 结论 |
|---|---|---|
| 1. 重量点估计 | 严格 hold-out MAPE 22.0%（开发口径 9.44% 不进摘要） | 已接近单图经验天花板 |
| 2. 7 方法共形大比武 | AEC-S 91.0% / 76g（⚠️ 泄漏版；诚实版 90.4% / 74g） | 达标者中区间最窄，统计显著；结论在诚实协议下不变 |
| 3. 逐段分析 | 500g+ 覆盖 71.8%→84.3%（⚠️ 派生自泄漏版 AEC-S） | 分层权重确实逐段自适应 |
| 4. 营养素点估计 | 热量 PMAE 12.6%（上限 7.5%） | 瓶颈在密度不在重量 |
| 5. 消融 | 每个组件均有贡献 | 设计不是堆料 |
| 6. 营养素区间 | 覆盖 89.7–90.6%，nWinkler 2.42 | 最优；密度误差主导不确定性 |
| 7. 诚实性 | 泄漏仅值 3g；double-dipping 被证伪；最终推荐 AEC-S2m 90.4% / 76g / Winkler 171 | 方法可信，失败模式刻画清楚 |
| 附加. DINOv2 | 31.3% ≈ ResNet18-3ch | 天花板是信息性的，不是架构性的 |

**读数口诀**：先看覆盖率够不够 90%（不够直接淘汰）→ 再比宽度 / Winkler（越小越好）；± 是 10 次试验波动；PMAE 是相对真值的百分比误差；Oracle 是作弊上限不可超越；看到标 ⚠️ 的数字记得查 §9(e) 的泄漏影响表。
