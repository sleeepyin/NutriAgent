## 1. 论文主线

**一句话**：单张食物图像估重不准，是因为缺信息，不是因为模型不够强。本文先给出可信区间（估计），再说清缺的是哪三类信息（诊断），最后让系统自动补能补的信息、补不了的就拒答（行动）。

| 贡献 | 一句话主张 | 主要证据 |
|---|---|---|
| 1. 估计：AEC-S | 按重量分层的自适应集成共形，在覆盖率达标的前提下区间更窄 | E2、E3 |
| 2. 诊断：三因子分解 | 单目估重误差来自尺度、密度、域偏移三个因子，每个因子都能在同一数据集内单独量化 | D1–D6、表 4 |
| 3. 行动：诊断驱动的信息路由 | 三个因子的可修复程度不同（尺度看当前场景、密度靠先验知识、域偏移只能靠校准数据），据此路由到不同动作，组合之后覆盖率仍有保证 | A1–A5 |

四个数据集各管一件事：**N5K 能做到什么 → MF3D 为什么做不到更好 → ECUSTFD 补上尺度后怎样 → NV-Real 离开训练域会怎样。**

## 4. 补做实验设计（5 项 + 1 次重跑）

### 4.0 一次 VLM 推理喂所有实验

每张图只问 VLM 一次，输出固定 JSON，结果缓存，供 D6、A2b、A3、A4、A5 共用：

```json
{"food_name": "...", "form": "rigid|prepared|liquid|stacked",
 "references": [{"object": "coin", "bbox": [...], "size_mm": 25.0, "conf": 0.9}],
 "weight_guess_g": 120, "scene": "...", "out_of_domain": false}
```

范围：四个数据集的留出集（N5K 测试半、ECUSTFD 88、MF3D 376、NV-Real 菜品划分测试 177），MF3D 每个物体固定取一个视角。提示词里不放任何重量标签。

### R0. N5K 重跑（E1–E5）

- **协议**：严格 hold-out（菜品不相交，2,608 训练 / 652 测试），测试集随机对半分校准/评估，重复 10 次；分位数用顺序统计量 k = ⌈(n+1)(1−α)⌉。
- **对比方法**：Split、Normalized、Mondrian、CQR、AEC（全局权重）、AEC-S、AEC-S2m。CQR 是审稿人默认会要的标准基线，必须进主表。
- **报告**：覆盖率、宽度、Winkler（均值 ± 标准差）+ 对最强基线的配对检验；点估计同时报 MAPE / WAPE / MAE。
- **预期**：AEC-S 约 90.4% / 74 g；如果对 Mondrian 的优势不显著，就如实写“覆盖达标、Winkler 更低”，不夸大。

### D6. VLM 直接看图估重

- **目的**：回应“为什么不直接问大模型”这个必然出现的审稿问题，同时作为“瓶颈在信息、不在模型”的第二条证据。
- **做法**：用 §4.0 的 `weight_guess_g`，在四个数据集上分别报误差，和本文的方法放在一起比。
- **两种结果都能写**：VLM 差 → 加强“信息瓶颈”论点；VLM 在某些数据集上好 → 把它作为密度先验的来源，正好支撑 A2。

### A2b. VLM 看图自动命名 + 名称先验

- **做法**：用 VLM 输出的 `food_name` 替换 E14 里的标注类别名，其余代码和 τ=4 不变。
- **报告**：命名准确率（精确匹配 + 同义匹配）；WAPE / MAE 与 A2a 对比；命名错误样本的误差单独统计。
- **判定**：WAPE 仍明显低于类别中位数 → 可写“密度层全自动”；否则只写 A2a，并把自动命名列为局限。

### A3. VLM 自动找参照物（只做 ECUSTFD）

- **做法**：用 VLM 给出的参照物框和规范尺寸定标，跑和 E3 相同的端到端流程。
- **对照**：标注硬币框（12.9%）；无定标（D4）；经典圆检测（Hough），作为非 VLM 的自动化对照。
- **报告**：检出率、尺寸召回误差、端到端 MAPE / WAPE。
- **兜底**：如果 VLM 定位不准而 Hough 可用，就写“自动检测”而不强调 VLM，尺度层的主张不受影响。
- MF3D / N5K 上的参照物覆盖率统计降为可选项，只用来在讨论节给出适用边界的数字。

### A4. 域外检测 + 选择性拒答

- **数据**：N5K 测试集（域内）∪ NV-Real 测试集（域外）。
- **检测器**：(a) 共形非一致性分数；(b) VLM 的 `out_of_domain` 判断；(c) 二者取或。
- **报告**：AUROC；拒答率 vs 剩余样本误差 / 覆盖率曲线（图 8）。可选加一组“检测到域外后改用联合训练模型”（D5 已有该模型）。
- **主张上限**：系统能识别出不该相信自己的样本，不声称在域外仍有 90% 覆盖。

### A5. 端到端混合流（核心）

- **数据**：四个数据集的留出集混成一条流，隐藏来源标签；另划出独立的策略集和校准集。
- **路由规则（固定，来自第 5 章）**：判为域外 → 拒答；有深度通道 → N5K 深度模型；检测到参照物 → 定标估计；否则 → 名称先验收缩。
- **对照**：每个单一动作用于全部样本；按真实来源路由（A1 的推广）；VLM 路由；逐样本 oracle（只作上界）。
- **共形**：按路由结果分组校准（路由只依赖输入图像，所以分组校准合法）；报总体和各路由组的覆盖率与宽度。
- **报告**：WAPE / MAE / MAPE、覆盖率、宽度、拒答率、路由准确率（参照物检出对 ECUSTFD 标注，域外判断对 NV-Real 来源）。
- **预登记判定**：VLM 路由显著优于最佳单一动作，并接近按来源路由 → 主张成立。只接近按来源路由 → 写成“不需要来源标签就能恢复按组路由的收益”，部署时样本本来就没有来源标签，这个结论仍然有意义。
- **写作提醒**：卖点是“诊断 → 动作”的映射和组合后的覆盖保证，**不是**路由本身有多聪明——规则本质上是 if-else，不要包装成智能决策。

## 5. 口径修正（写作前必须改）

1. **E2 统一协议**：旧表 1 的 Split / Normalized / Mondrian 跑在 10 次 50/20/30 随机划分上（即 9.44% 那套开发口径），AEC-S 诚实版跑在严格 hold-out 上。必须全部在严格 hold-out 上重跑，才能放进同一张表。
2. **营养素主数字**：旧方案用的“热量 12.6%”来自开发口径；按“只报严格 hold-out”的规则，正文应使用 22.8%（脂肪 36.5% / 碳水 39.4% / 蛋白质 33.7%）。
3. **跨数据集比较改为同数据集对照**：“密度离散 21.8% ≈ N5K 22.0%”“ECUSTFD 12.9% < N5K 18.4%”都是拿两个数据集的数字硬比，审稿人会质疑。主证据换成同一数据集内的对照（D1 真值密度 vs 留一密度；D4 有/无硬币；D5 同一模型的域内 vs 域外），跨数据集数字只作“同一量级”的旁证。
4. **主指标**：全文统一以 **WAPE + MAE 为主、MAPE 为辅**，每张表都同时列出三者。理由：MF3D 小物体多，MAPE 会超过 100% 且不稳定；按克计的误差符合临床上碳水累计的方式。必须全文统一，不能只在行动层换指标，否则像挑指标。能从现有 CSV 补算 WAPE 的（D1、D4）直接补算。

## 9. 写作红线（沿用 v1.6）

1. **不和已放弃的方案比**：不出现“改为”“不再”“取消”“v1.x”之类的措辞，只正面陈述最终设计。
2. **不预先防御**：每个设计决策最多给一条正面理由，负面结果直接陈述事实和机理。
3. **只和可引用的东西比**：每一处“优于”的对比对象，要么能附公开文献，要么是本文实验节里定义的对照。

**写作门控**：E2（定估计层数字）、A2b（定密度层能否写“全自动”）、A5（定路由主张的强弱）出结果前，不写对应章节。第 4–5 章可以在 R0 完成后先写。
