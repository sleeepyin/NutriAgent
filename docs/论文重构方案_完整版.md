## 0. 一句话定位

**本文提出一个"估计—诊断—行动"三层框架：先用共形预测为食物重量/营养素估计建立可信区间（Estimate），再用四个数据集系统诊断出单目视觉的三类信息瓶颈（Diagnose），最后提出主动信息获取 Agent 在成本约束下补齐缺失信息（Act）。**

---

## 1. 现有论文为什么"乱"

现有 `paper_cn.md` 的问题可以归结为四点：

### 1.1 贡献罗列而非递进

现有论文列出 7 项贡献，彼此之间是平行关系（基预测器、AEC-S、基准测试、营养素、AEC-S2m-N、诚实性、天花板归因），读者不知道"为什么做了 A 之后要做 B"。实际上这些实验之间存在一条严密的因果链，但论文没有把它讲出来。

### 1.2 诊断实验像补丁

MetaFood3D、ECUSTFD、NV-Real 三组实验被塞在 §6 讨论章节，读起来像"审稿人要求补的实验"，而不是论文的有机组成部分。实际上这三组实验是整个故事最关键的转折——它们回答了"为什么 18.4% 天花板存在、以及怎么绕过去"。

### 1.3 数字口径混乱

同一篇论文中 9.44%（10 次重切分，含训练泄漏）、22.0%（严格 hold-out WAPE）、31.4%（3ch hold-out MAPE）三个数字并存，读者无法判断系统的真实精度。且摘要引用的 AEC-S 91.0%/76g 是带评估泄漏的版本，诚实版 90.4%/74g 只在 §5.7 出现。

### 1.4 Agent 创新点无处安放

CAIA-MM 方案洋洋洒洒写了 2600 行实施细节，但与现有论文的关系始终是"附加件"，没有回答"为什么前面做了这么多诊断实验之后自然导向一个 Agent"。

## 2. 核心叙事主线：Estimate → Diagnose → Act

把整篇论文重构为三幕剧，每一幕回答一个递进问题：

```
第一幕 Estimate：如何给食物重量/营养素估计配上可信的不确定性区间？
    └── 答案：AEC-S 分层自适应集成共形预测
    └── 产出：Nutrition5K 上 90% 覆盖率、76g 区间的可靠系统

第二幕 Diagnose：这个系统的误差上限为什么存在？卡在什么信息上？
    └── 答案：尺度歧义 + 密度离散 + 域偏移，三类信息瓶颈
    └── 产出：四个数据集的系统诊断证据链

第三幕 Act：既然知道缺什么信息，能否让系统主动获取？
    └── 答案：CAIA-MM 共形主动信息获取 Agent
    └── 产出：成本受控的"何时停止/何时请求/何时拒答"决策
```

三幕之间的关系是**必然递进**，不是平行罗列：

- 不做 Estimate，就没有不确定性度量，Diagnose 无从谈起；
- 不做 Diagnose，就不知道缺什么信息，Act 就是盲目堆功能；
- 不做 Act，Diagnose 就只是消极认怂，没有建设性出路。

## 3. 创新点重构：三个，不是七个

### 创新点 1：AEC-S 分层自适应集成共形预测

**一句话**：在共形预测框架内，为不同重量区间学习基方法的自适应凸组合权重，并用经验收缩稳定稀疏区间的权重估计。

**支撑实验**：
- N5K 上 7 种共形方法大比武（表 1）
- 逐段权重分析（表 2–4，证明"全局一组权重是次优的"）
- 消融实验（表 6，证明分层有独立贡献）
- 营养素共形区间 AEC-S2m-N（表 7，证明框架可扩展）
- 诚实性实验（表 8–9，证明结论在修正协议下不变）

**为什么站得住**：不是在已有方法上做增量改进，而是解决了"异质误差分布下单一共形策略次优"的通用问题。分层 + 收缩的组合是新的。

### 创新点 2：信息瓶颈的系统性分解

**一句话**：用四个互补数据集，把"单图食物重量估不准"这个模糊观察，分解为三个可独立验证的物理因子——尺度歧义、密度离散、域偏移——并给出每个因子的量化贡献。

**支撑实验**：
- MetaFood3D Phase 1：Oracle 误差分解（密度贡献 21.8% ≈ 全部单目难度 22.0%；体积 ±10% 只贡献 2.6pp）
- MetaFood3D Phase 2'：CNN 学密度输给查表（证明外观不携带超类别密度信息）
- MetaFood3D Oracle-6：SAM 3D 零样本崩溃（证明最强单图 3D 模型也逃不出去）
- ECUSTFD E1–E3：硬币消尺度歧义后刚体食物 12.9% < 18.4% 天花板（建设性验证）
- NV-Real 零样本：域偏移下 PMAE 103.7%、覆盖率 33%（域偏移因子的量化）
- N5K DINOv2 消融：换更强骨干精度零提升（信息性而非架构性瓶颈）

**为什么站得住**：这不是"做了一个数据集实验"，而是用四个数据集从不同角度反复验证同一个三因子分解假设。每个数据集回答一个子问题，组合起来形成完整论证链。

### 创新点 3：名称先验收缩，而不是逐条收益回归

**一句话**：参照物仍然是刚体食物的动作；没有参照物时，用本机 Qwen3.8-27B 根据食物名称给出的典型重量，按策略集留一法选出的系数向经验类别中位数收缩，并在收缩之后重做终端共形。

**已经跑完的对照**：
- 逐条收益回归：出折 R² 为负，或在 ECUSTFD 上测试 R² = 0.035，打不赢「始终使用硬币」。
- 分组冻结：ECUSTFD 选硬币、MetaFood3D 的每一组都选类别中位数。它只是两个固定动作，宏平均上的优势几乎全部来自硬币。
- 名称先验收缩：MetaFood3D 留出样本的 WAPE 从 0.587 降到 0.525，MAE 从 81.2 g 降到 72.7 g；MAPE 从 1.64 升到 2.73。ECUSTFD 仍选硬币，留出 MAPE 0.123，名称先验打不赢硬币。

**为什么还没有写成论文正文**：WAPE 和 MAE 的改进是真的，MAPE 变差也是真的。正文要等这个取舍被明确写成主要指标之后再改。数字和限制见第 16 节。

## 4. 四个数据集的角色分配

每个数据集只承担一个论证职责，不要试图让一个数据集证明所有事：

| 数据集 | 角色 | 证明什么 | 关键数字 |
|---|---|---|---|
| **Nutrition5K** | 主场 | 系统在受控条件下能做到什么 | AEC-S 90.4%/74g（诚实版）；热量 PMAE 12.6% |
| **MetaFood3D** | 诊断室 | 为什么做不到更好——密度是瓶颈 | 密度离散 21.8%；CNN 30.3% vs 查表 26.2%；SAM 3D MAPE 100% |
| **ECUSTFD** | 验证场 | 补上缺失信息后能做到什么 | 硬币定标端到端 12.9% < 18.4% 天花板 |
| **NV-Real** | 压力测试 | 离开训练域会怎样 | PMAE 103.7%；覆盖率 33%；联合训练修复到 23.9% |

四个数据集合起来回答：**能做什么（N5K）→ 为什么（MF3D）→ 怎么破（ECUSTFD）→ 现实考验（NV-Real）**。

## 7. 各章节写作要点

### 7.1 摘要（建议结构）

```text
第 1 句：问题背景——食物重量/营养素估计需要可信不确定性
第 2 句：现有局限——单目视觉存在信息瓶颈，标准共形方法次优
第 3 句：方法 1——AEC-S，在 N5K 上达到 90.4% 覆盖、74g 宽度
第 4 句：方法 2——四数据集诊断，将瓶颈分解为尺度/密度/域三因子
第 5 句：方法 3——CAIA-MM Agent，成本受控的主动信息获取
第 6 句：核心结果——Agent 在 X% 成本下恢复 Y% 精度
第 7 句：意义——从被动估计到主动获取的范式转变
```

### 7.2 引言的贡献段（3 项，不是 7 项）

```text
1. 我们提出 AEC-S，一种分层自适应集成共形预测方法，
   通过为异质重量区间学习基方法的凸组合权重，
   在 Nutrition5K 上实现了 90.4% 覆盖率与 74g 平均区间宽度，
   并扩展到四种宏量营养素的联合区间估计。

2. 我们通过四个互补数据集的系统实验，
   将单目食物重量估计的性能瓶颈分解为三个可独立验证的物理因子：
   尺度歧义、密度离散与域偏移，
   并证明最强单图 3D 重建模型同样无法跨越该天花板。

3. 我们提出 CAIA-MM，一个由共形不确定性驱动的主动信息获取 Agent，
   它在停止、参照物、视角、深度、语义提问与拒答之间做成本受控路由，
   并通过三段隔离校准保证自适应决策后的有限样本覆盖有效性。
```

### 7.3 第 4 章（Estimate）写作要点

- **4.2 基预测器**：只报严格 hold-out 结果（WAPE 21–22%，MAPE 31.2%），9.44% 标记为开发结果或删除
- **4.5 实验**：表 1 必须用诚实版数字（90.4%/74g），泄漏版只在诚实性分析中作为对照
- **4.6 诚实性**：这是论文的加分项而非减分项，主动呈现修复过程和结论不变性

### 7.4 第 5 章（Diagnose）写作要点

- **5.1 三因子假设**：用一个清晰的总图展示"重量 = 体积 × 密度，体积需要尺度，密度需要语义/物理信息"
- **5.2–5.3 MetaFood3D**：核心叙事是"两条补救路线都被证伪"——学密度不行（CNN 输查表），搞 3D 也不行（SAM 3D 崩溃）。蓝莓悖论作为具象案例
- **5.4 ECUSTFD**：转折——"但在密度可观测的刚体食物上，一枚硬币就够了"。12.9% < 18.4% 是关键对比
- **5.5 NV-Real**：域偏移的代价。33% 覆盖率 vs 承诺 90%，是"共形预测不是跨域免死金牌"的教科书级案例
- **5.6 DINOv2**：一句话——"换更强骨干精度零提升，瓶颈是信息不是模型"

### 7.5 第 6 章（Act）写作要点

- **6.1 从诊断到行动**：这是全文最重要的过渡段。逻辑是：第 5 章证明了三类信息瓶颈，第 6 章构建一个系统来主动补齐这些信息
- **6.2 Agent 形式化**：用数学语言定义 episode、状态、动作、成本、停止条件。这是与"if-else 规则"的本质区别
- **6.5 共形安全**：三段隔离（D_policy 学策略 → D_cal 算分位数 → D_test 一次性评估）是方法学贡献，不是工程细节
- **6.6 实验**：即使只有公开数据的可行性版本，也要包含 Agent vs 固定协议的比较

## 10. Agent 创新点整合方案

### 10.1 为什么现有 AEC-S 撑不起一篇论文

AEC-S 的核心贡献是"在共形框架内做分层权重学习"。这个贡献的问题在于：

1. **增量感太强**：是在 AEC 基础上加分层 + 收缩，审稿人可能认为是工程改进
2. **应用领域太窄**：只在食物重量上验证，通用性存疑
3. **实验故事不完整**：只有"我们提出了方法，它work了"，没有"为什么需要它、它解决了什么本质问题"

### 10.2 三层框架如何解决这个问题

把 AEC-S 从"唯一创新"降级为"三层框架的第一层"，它的价值立即提升：

- **AEC-S 不再是终点**，而是"建立了可信的不确定性度量"这个必要基础
- **诊断实验不再是附录**，而是"发现 AEC-S 也救不了的信息缺口"的必然下一步
- **Agent 不再是附加件**，而是"既然知道缺什么，就主动获取"的逻辑终点

三层框架下，每个创新点都因为前后文而变得必要：

```
没有 AEC-S → 无法量化不确定性 → 诊断无从谈起
没有诊断 → 不知道缺什么信息 → Agent 就是盲目堆功能
没有 Agent → 诊断只是认怂 → 没有建设性出路
```

### 10.3 Agent 部分的最小可行方案

如果时间和资源有限，Agent 部分可以只做公开数据可行性版本：

**必做实验（最小集）**：

| 实验 | 数据来源 | 内容 |
|---|---|---|
| E1 单工具价值 | 现有四个数据集 | 分别量化"加深度/加视角/加参照物/加语义"对各子群的收益 |
| E2 动作异质性 | 现有数据交叉分析 | 证明不同食物类型需要不同动作（刚体→参照物，制备→语义） |
| E3 固定协议 vs 自适应 | NV-Real + ECUSTFD | 在配对数据上比较"总是请求参照物"vs"按需请求" |

**可选实验（增强版）**：

| 实验 | 数据来源 | 内容 |
|---|---|---|
| E4 共形有效性 | 新采配对数据 | 三段隔离 vs naive 复用的覆盖对比 |
| E5 LLM 消融 | 新采配对数据 | 有无 LLM 的数值性能对比 |
| E6 用户负担 | 用户实验 | 交互时间与主观负担 |

### 10.4 Agent 部分的叙事锚点

Agent 部分的每一段都应该回指第 5 章的诊断结论：

| Agent 设计决策 | 对应的诊断证据 |
|---|---|
| 动作空间包含"请求参照物" | ECUSTFD 证明硬币定标可破天花板（§5.4） |
| 动作空间包含"语义提问" | MF3D 证明密度不可从外观学习（§5.2） |
| 动作空间包含"拒答" | NV-Real 证明域外承诺崩溃（§5.5） |
| 控制器使用因素化不确定性 | 三因子分解（§5.1） |
| 刚体食物优先路由到参照物 | E2 刚体 7.9% vs MF3D 25.0%（§5.4） |
| 制备食物优先路由到语义/拒答 | 蓝莓悖论 33% 密度波动（§5.2） |

## 16. v1.1 行动层：Qwen3.8-27B 名称先验

### 16.1 前两个行动层方案为什么不够

| 方案 | 做法 | 结果 |
|---|---|---|
| 近视价值（CAIA-MM E07） | 用特征回归每一条样本的动作收益 | 四个动作的出折 R² 约 −0.01。策略几乎总是停止，归一化 Winkler 4.264，差于始终语义提问的 3.776 |
| 分组冻结（E13） | 策略集上为每个「数据集 × 形态」冻结一个动作 | ECUSTFD 选硬币，测试 MAPE 0.129，优于类别中位数 0.246。MetaFood3D 每一组都选类别中位数，和「始终语义」没有差别 |

分组冻结证明了「硬币和类别先验不是同一个动作」，但模型没有在同一数据集里按样本改变决定。

### 16.2 新做法

本机 `llama-server` 在 `127.0.0.1:18080` 提供 `qwen3.8-27b`（视觉权重已加载，这次实验没有喂图像）。127 个类别名各问一次，温度 0，只要求 JSON：`typical_mass_g` 和 `form`。提示词不包含重量标签。回复缓存在 `agent_extension/results/e14_llm_prior/category_cache.json`。密钥不进仓库。

对 MetaFood3D，候选是：停止（策略集全局中位数）、经验类别中位数、纯模型重量、以及

\[
\hat y = \frac{n\bar y_{\mathrm{cat}} + \tau\, y_{\mathrm{LLM}}}{n+\tau}
\]

τ 取 0、1、2、4、8、16、32。选择只用策略集，并且类别中位数要留一，避免单样本类别在策略集上误差为 0。选出的是 τ = 4。ECUSTFD 的候选里还有硬币定标；策略集留一后仍然选硬币。

终端分位数只用校准集，按数据集分开，顺序统计量 \(k=\lceil(n+1)(1-\alpha)\rceil\)，α = 0.10。

### 16.3 留出结果

留出集 = 校准集 + 测试集，都没有参与选 τ。

| 数据集 | 规则 | MAPE | WAPE | MAE |
|---|---|---|---|---|
| ECUSTFD（n=88） | 硬币，策略集选定 | 0.123 | 0.111 | 13.7 g |
| ECUSTFD | 经验类别中位数 | 0.262 | 0.194 | — |
| ECUSTFD | 纯名称先验 | 0.428 | 0.324 | — |
| MetaFood3D（n=376） | 收缩 τ=4 | 2.733 | 0.525 | 72.7 g |
| MetaFood3D | 经验类别中位数 | 1.638 | 0.587 | 81.2 g |
| MetaFood3D | 纯名称先验 | 3.354 | 0.558 | 77.2 g |
| MetaFood3D | 全局中位数 | 4.204 | 0.735 | 101.7 g |

MetaFood3D 上，收缩相对经验中位数的 WAPE 下降约 0.061，自助法 95% 区间 [0.003, 0.123]，不包含 0。MAPE 上升约 1.09，区间 [0.43, 1.93]，也不包含 0。小物体被拉向模型给出的典型重量，百分比误差变大，克误差变小。稀有类别（策略集同类少于 3 个，留出 n=259）上，WAPE 从 0.611 降到 0.510，区间 [0.020, 0.183]。

收缩预测在 MetaFood3D 测试集上的终端覆盖率是 0.899，平均宽度 251 g。

策略集菜单里，按 WAPE 最优的是 τ=4，按 MAPE 最优的是 τ=0（接近纯经验中位数）。这个取舍在看留出集之前就已经出现在策略集上，不是事后改的。

### 16.4 论文里可以怎么写，以及现在还不能写的

可以写的行动层句子：

1. 有硬币时，名称先验和类别中位数都不如硬币。ECUSTFD 留出 MAPE 0.123 对 0.262 对 0.428。
2. 没有硬币、类别样本又少时，把大模型的名称重量以 τ=4 收缩进经验中位数，能降低 WAPE 和 MAE。
3. 同一规则使 MAPE 变差。如果论文的主指标是 MAPE，这一条不能写成精度提升。

正文仍然不改，直到确定主指标是 WAPE/MAE 还是 MAPE。若主指标保持 MAPE，行动层的正面结果只剩下 ECUSTFD 的硬币，大模型先验应写成负结果：它帮助克误差，伤害百分比误差。

复现：`python -m agent_extension.experiments.e14_llm_prior --skip-query`。首次查询去掉 `--skip-query`，需要本机 18080 端口上的 Qwen 服务。

## 15. 总结

这篇论文的核心价值不在于"我们提出了一个新方法"，而在于**建立了一个从被动估计到主动获取的完整范式**：

1. **Estimate** 层回答"如何可信地估计"——AEC-S
2. **Diagnose** 层回答"为什么估计有极限"——三因子信息瓶颈分解
3. **Act** 层回答"如何突破极限"。逐条收益回归没有成立。有参照物时用硬币。没有参照物时，Qwen3.8-27B 的名称重量以 τ=4 收缩进类别中位数：WAPE 和 MAE 下降，MAPE 上升。细节在第 16 节。

三层的前两层已经有证据。第三层目前只能诚实写成：物理参照物降低刚体食物的 MAPE；名称先验降低克误差，同时提高百分比误差。在选定主指标之前，不把第三层写成已经突破天花板。
