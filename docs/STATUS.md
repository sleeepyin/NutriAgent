## 要证的问题

训练期可以使用俯视 RGB-D 和食材标注。测试期的学生只输入单张俯视 RGB：不输入深度图，不输入食材名称，不查 USDA 表，也不在测试时跑单目深度估计网络。测试时也不运行教师或文本编码器。学生不得先预测食材再去查表。这一步不实现学生。

盘级营养仍是物理乘积 `ŷ = M̂ × ρ̂`。质量用克。密度是每克能量或每克宏量。乘积回到盘级能量与三种宏量。几何路径专攻总质量 `M̂`，成分路径专攻每克密度 `ρ̂`。两条路径都要预测，不要把两者混在同一个黑盒回归头里，也不要用真值质量或真值密度去拼盘级指标。能量密度不再单独回归，写成 `ρ̂_cal = 9ρ̂_fat + 4ρ̂_carb + 4ρ̂_pro + Δρ̂_cal`。Δ 是一个小的学习残差头。禁止硬约束。这条残差是本仓库 DiGI-Nutri 的冻结写法。当前复现不把它套到 DPF-Nutrition 或 Swin-Nutrition 上。

损失里已经冻结的 `L_task`、划分、质量乘密度和高度图公式都不为追数而改。深度预处理仍是相对桌面高度，不再做整图 [0, 1] 归一化。`depth_raw.png` 是 16 位图，单位 1e-4 米。先把原始值换成毫米，记为 `D_raw`（1 个原始单位 = 0.1 mm）。取图像四周边缘上、排除缺失深度 0 之后的这些毫米值的中位数作为桌面基准 `D_table`。0 不是有效桌面深度。食物相对高度为 `clip(D_table - D_raw, 0, 150 mm)`。再按固定比例线性缩放到 [0, 1]：0 mm 对应 0，150 mm 对应 1，不按单张图重新拉伸。然后做一次 3×3 形态学闭运算填洞，复制成 3 通道，送入预训练主干。冻结的就是这一条：桌面扣减、截断到 0–15 cm、一次 3×3 闭运算、复制成 3 通道，并且计算 `D_table` 时缺失深度 0 不进四周中位数。

这不是新的高度公式。#88 开训前的排查记到，2754 条训练盘里有 65 条（0.023602033405954976，约 2.36%）按旧的含零中位数会得到 `D_table == 0`、整张高度图全零。修正是把缺失深度 0 从四周中位数里除掉。桌面扣减、0–15 cm 截断和一次 3×3 闭运算没有改。这个修正已经是冻结高度公式的一部分。这一轮不另设阈值，也不再把排查当成还没做的解锁项。本仓库质量头若用高度图，用现行高度图里高度为正的像素当前景，不另设会改这条公式的阈值。复现不改这条公式。

非泄漏 USDA 静态密度先验只给本仓库密度路径。从 Nutrition5k 的 `ingredients_metadata.csv` 或 USDA 公开表，取每种食材固有的每克热量与宏量密度。这是公开字典，不得含任何测试盘的克重或总营养。不得把盘内成分级热量或宏量当成教师输入。学生训练和学生测试都不得查这张表。#88 与 #91 里 `T_ing` 的留出数字、#93 的 ResNet-101 `T_multi`，以及 #95 的 ConvNeXt-Small `T_multi`，都是未合并的失败记录，不是这一轮的结果，也不把那些权重复用为起点。当前复现不加载这些权重。

任务损失 `L_task` 仍是按训练集均值归一化的 SmoothL1，公式不改，不回到逐盘小分母 PMAE 损失：

`L_task = SmoothL1(ŷ, y) / σ_mean + 0.5 · SmoothL1(M̂, M) / σ_M + 0.5 · SmoothL1(ρ̂, y / max(M, 5.0))`

`σ_mean` 是训练集里该营养素的均值，按营养素对齐后再相除，用来把损失放到数据集级 PMAE 的尺度上。`σ_M` 是训练集质量的均值。密度监督的目标是 `y / max(M, 5.0)`，用的是真值质量和真值营养；质量低于 5 g 的盘，分母截断在 5 g。密度这一项按上式书写，不再另除一个尺度。`ŷ = M̂ × ρ̂` 使用预测质量与预测密度，不把真值代进乘积里去报盘级误差。

本仓库在冻结的 `L_task` 之外，保留一项冻结的 `0.1 × SmoothL1(Δρ̂_cal, 0)`。能量密度是 `ρ̂_cal = 9ρ̂_fat + 4ρ̂_carb + 4ρ̂_pro + Δρ̂_cal`，不再单独回归。禁止硬 Atwater。看到留出之后不改 0.1，也不改 `L_task`。在 #93 的 507 盘留出标注上，`|能量 − (9×脂肪 + 4×碳水 + 4×蛋白)|` 的均值是 13.11 kcal；用真值宏量的 Atwater 代替标注能量，数据集 PMAE 已经是 5.13%。这条残差是 DiGI-Nutri 的冻结项。#95 已经用过。仍锁的下一轮教师继续用它，系数不改。当前的 DPF / Swin 复现不另加这一项，它们用各自论文的损失。
