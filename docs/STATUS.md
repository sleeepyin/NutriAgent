深度预处理改为相对桌面高度，不再做整图 [0, 1] 归一化。`depth_raw.png` 是 16 位图，单位 1e-4 米。先把原始值换成毫米，记为 `D_raw`（1 个原始单位 = 0.1 mm）。取图像四周边缘上这些毫米值的中位数作为桌面基准 `D_table`。食物相对高度为 `clip(D_table - D_raw, 0, 150 mm)`。再按固定比例线性缩放到 [0, 1]：0 mm 对应 0，150 mm 对应 1，不按单张图重新拉伸。然后做一次 3×3 形态学闭运算填洞，复制成 3 通道，送入预训练主干。

非泄漏 USDA 静态密度先验只给成分教师。从 Nutrition5k 的 `ingredients_metadata.csv` 或 USDA 公开表，取每种食材固有的每克热量与宏量密度。这是公开字典，不得含任何测试盘的克重或总营养。不得把盘内成分级热量或宏量当成教师输入。学生训练和学生测试都不得查这张表。成分教师自己的诊断性测试仍使用 RGB、食材名和这本静态字典。那次诊断不是论文的测试期方法。

任务损失改为按训练集均值归一化的 SmoothL1，去掉逐盘小分母 PMAE 损失：

`L_task = SmoothL1(ŷ, y) / σ_mean + 0.5 · SmoothL1(M̂, M) / σ_M + 0.5 · SmoothL1(ρ̂, y / max(M, 5.0))`

`σ_mean` 是训练集里该营养素的均值，按营养素对齐后再相除，用来把损失放到数据集级 PMAE 的尺度上。`σ_M` 是训练集质量的均值。密度监督的目标是 `y / max(M, 5.0)`，用的是真值质量和真值营养；质量低于 5 g 的盘，分母截断在 5 g。密度这一项按上式书写，不再另除一个尺度。`ŷ = M̂ × ρ̂` 使用预测质量与预测密度，不把真值代进乘积里去报盘级误差。

主报仍是能量与三种宏量的 MAE。质量并列报告，不作为单独通过条件。数据集级 PMAE 和逐盘 PMAE 都要报。

**稳定优于**指：留出集上（方法 − 对照）的 95% 区间整体落在 0 以下。bootstrap 做 2000 次，按物理餐盘分组。分组用 `dish_id` 以及已知重拍组。同一只物理餐盘的重拍不作为独立样本重抽。能量与三种宏量都要看。MAE、数据集级 PMAE、逐盘 PMAE 都按这条规则检验。质量的区间只并列记录，不进入通过条件。

### v1 第二阶段模块

DSD + `L_orth`、GOFF 与 `w_i` 不再是官方路线，由物理乘积解耦取代。定义留在这里，避免以后把它们重新当成默认下一步。保持锁定，不实现。不得用它们挽救未通过的 Q0、Q1 或 Q2。

- **几何-语义双子空间解耦与正交约束（DSD + `L_orth`）。** 学生末端两个并行投影分支 `F_geo^S` 与 `F_sem^S`。正交损失是归一化内积的平方 Frobenius 范数：`L_orth = || (F_geo^S)^T F_sem^S ||_F^2`。
- **门控正交融合（GOFF）。** 用通道门控自适应融合两个子空间，而不是简单拼接或相加。
- **教师置信度自适应重加权。** 按教师在样本 `i` 上的回归误差 `e_i^T` 计算 `w_i = exp(-α · e_i^T)`。
- **v1 完整目标（仍锁，且已不是官方路线）。** `L_total = L_task(y, ŷ_S) + λ1 · w_i · L_geo(A_T, A_S) + λ2 · w_i · L_sem(F_sem^T, F_sem^S) + λ3 · L_orth(F_geo^S, F_sem^S) + λ4 · L_aux_ing(y_ing, ŷ_ing)`。原稿建议的初始权重是 `λ1 = 1.0`、`λ2 = 0.5`、`λ3 = 0.1`、`λ4 = 0.2`。这组权重不是停止规则，也不提前变成任何一步的写法。

v1 的空间亲和力几何蒸馏、整图深度归一化、逐盘小分母 PMAE 损失，以及 Q0 失败后继续蒸馏，都已停下。不要把它们写进新版 Q0。
