## 要证的问题

训练期可以使用俯视 RGB-D 和食材标注。测试期的学生只输入单张俯视 RGB：不输入深度图，不输入食材名称，不查 USDA 表，也不在测试时跑单目深度估计网络。测试时也不运行教师或文本编码器。学生不得先预测食材再去查表。这一步不实现学生。

盘级营养仍是物理乘积 `ŷ = M̂ × ρ̂`。质量用克。密度是每克能量或每克宏量。乘积回到盘级能量与三种宏量。几何路径专攻总质量 `M̂`，成分路径专攻每克密度 `ρ̂`。两条路径都要预测，不要把两者混在同一个黑盒回归头里，也不要用真值质量或真值密度去拼盘级指标。能量密度不再单独回归，写成 `ρ̂_cal = 9ρ̂_fat + 4ρ̂_carb + 4ρ̂_pro + Δρ̂_cal`。Δ 是一个小的学习残差头。禁止硬约束。

Nutrition5k 原论文报告，质量已知时只预测每克密度，误差可低至约 9.5%。这是动机，不是本轮结果，也不是通过条件。

若要让纯 RGB 学生有机会走到 DPF-Nutrition 一类纯 RGB 赛道的公开水平附近，必须先把特权教师的绝对精度拉高。#93 教师在官方 507 盘上的能量数据集 PMAE 是 17.4041，五项平均 19.5061，还不够作为蒸馏天花板。DPF-Nutrition 公开的数据集 PMAE 是能量 14.7%、质量 10.6%、五项平均 17.8%。论文里的 PMAE 定义为 MAE 除以真值均值，与本仓库的数据集 PMAE 一致，但没有在本仓库 `official_depth_test` 的 507 盘上复现。这些数字只作文献参照，不进 Q0。不写 FPS，也不写「比 DPF 快 2 到 3 倍」。IGSMNet 与 PortionNet 的公开数字同样不进门禁。

任务损失 `L_task` 仍是按训练集均值归一化的 SmoothL1，公式不改，不回到逐盘小分母 PMAE 损失：

`L_task = SmoothL1(ŷ, y) / σ_mean + 0.5 · SmoothL1(M̂, M) / σ_M + 0.5 · SmoothL1(ρ̂, y / max(M, 5.0))`

`σ_mean` 是训练集里该营养素的均值，按营养素对齐后再相除，用来把损失放到数据集级 PMAE 的尺度上。`σ_M` 是训练集质量的均值。密度监督的目标是 `y / max(M, 5.0)`，用的是真值质量和真值营养；质量低于 5 g 的盘，分母截断在 5 g。密度这一项按上式书写，不再另除一个尺度。`ŷ = M̂ × ρ̂` 使用预测质量与预测密度，不把真值代进乘积里去报盘级误差。

### v1 第二阶段模块
