## 当前工作

当前工作是 **U1：可分离度感知的自适应营养估计粒度**。

Hand 等人已经回答了平均意义上「分割更细是否更好」。在 Nutrition5k 的 1056 张俯视 RGB 上，标准预处理下整盘平均 PMAE 为 19.91%。食材级显著更差：食材级减去整盘的配对差，95% 区间为 [1.51, 5.98] 个百分点，p=0.001（Hand et al., *Frontiers in Nutrition* 2026, 13:1927530，[10.3389/fnut.2026.1927530](https://doi.org/10.3389/fnut.2026.1927530)）。他们也写明：视觉上分得开的简单盘子上，食材级仍有竞争力；混合盘上误差会累积。这个平均结论本分支不再当作待证问题。

本分支要检验的问题是：测试时不看标签，也不用食材真值个数或真值掩膜，能否按盘估计视觉可分离度，选择整盘回归或食材级聚合，并且这种选择稳定同时优于「永远整盘」和「永远食材级」。

推理协议保持单张俯视 RGB。

## 停止规则

规则在第二阶段仍锁定时先写死。以后的实验沿用这些句子，不在看到留出结果之后改写。

**稳定优于**指：留出集上（方法 − 对照）的 95% 区间整体落在 0 以下。区间按盘配对，或按物理餐盘分组做 bootstrap。同一物理餐盘的重拍不作为独立样本重抽。审计须写下配对单位是 Hand 的 `dish_id`，还是合并重拍后的物理餐盘。本文件不预设重拍是否存在。

**稳定更差**指：同一区间整体落在 0 以上。

| 问题 | 算通过 | 算停止 |
|---|---|---|
| Q1 问题是否存在 | 用已登记、不泄漏真值的可分离度，事先分成高、低两档。高可分离档里，食材级减去整盘的 95% 区间不整体落在 0 以上，即食材级相对整盘不稳定更差。低可分离档里，该区间整体落在 0 以上，即食材级稳定更差。能量、脂肪、碳水、蛋白质都符合这一方向。 | 只有真值实例数能复现 Hand 的分层，而预先登记的无泄漏分数看不到这种交叉。问题就还不能在测试时操作化。看完测试结果再换分数，结果作废。 |
| Q2 简单切换是否有用 | 阈值只在训练/验证集上选好。留出集上，切换对能量和三种宏量都稳定优于永远整盘，也稳定优于永远食材级。 | 只打平两种固定粒度里更好的那个，或区间跨过 0。这不足以开发新算法。本轮不得再叠路由器或改损失去补救。 |

高低档的切分在看到留出结果之前写死。切分若要用数据来定，只用训练/验证。在测试集上选阈值或选分数，结果作废。

Q1 成立而 Q2 失败：停下来让 Triste 判断。不自动开始学习路由器。

Q1 和 Q2 都成立：是否开发算法另作决定。本文件不因此自动解锁新算法。
