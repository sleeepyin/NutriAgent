### 教师

几何教师的输入是 RGB 与官方真值深度。双流提取特征，再做跨模态通道-空间注意力融合，输出多尺度空间特征图 `F_geo^T`。深度图归一化到 [0, 1]。无效空洞用均值或中值填充。

成分教师用冻结的预训练文本编码器，默认 CLIP-Text，把食材名称编成菜品级语义向量，再用交叉注意力调制视觉特征，输出 `F_sem^T`。默认不加克重加权。

两个教师都先单独训到收敛，然后冻结，再训学生。

### 学生与损失

第一阶段的学生是纯 RGB 主干加多任务回归头，预测能量、质量与三项宏量。不要把学生拆成带正交约束的 `F_geo^S` 与 `F_sem^S`。不要做门控融合。

`L_geo` 把教师与学生的特征图展平为 `N = H'×W'` 个空间区域，各自计算余弦相似度关系矩阵 `A_T`、`A_S`，蒸馏相对高度差和食物 / 盘子边界拓扑。不要做像素级特征 L2。

`L_sem` 把教师的成分融合表征蒸馏给学生。

`L_aux` 是只在训练期启用的食材多标签分类头，损失用 BCE。测试时去掉。训练期可以用食材名称构造这个多标签目标。测试时不得再读食材名称。

`L_task` 是 PMAE 与 Smooth L1 的组合。能量、质量、脂肪、碳水、蛋白质五项都算。主报仍是能量与三种宏量。质量不进入通过条件。

## 仍锁的完整算法

下面来自完整 DiGI-Nutri 原稿。写在这里是为了不丢掉定义。第一阶段不实现。只有 Q1 与 Q2 都通过之后，才可以讨论是否解锁。通过不自动开工。它们只能用来检验能否在已经成立的天真联合蒸馏之上再加一点，不得用来挽救未通过的 Q1 或 Q2。使用之前必须先改本文件，并由 Triste 另作决定。

- **几何-语义双子空间解耦与正交约束（DSD + `L_orth`）。** 学生末端两个并行投影分支 `F_geo^S` 与 `F_sem^S`。正交损失是归一化内积的平方 Frobenius 范数：`L_orth = || (F_geo^S)^T F_sem^S ||_F^2`。用来避免同一特征向量同时拟合深度与食材时坍塌。
- **门控正交融合（GOFF）。** 用通道门控自适应融合两个子空间，而不是简单拼接或相加。原稿预期质量更偏几何，脂肪和蛋白质更偏成分。
- **教师置信度自适应重加权。** 按教师在样本 `i` 上的回归误差 `e_i^T` 计算 `w_i = exp(-α · e_i^T)`。用来避免学生模仿深度缺失或遮挡严重样本上的不可靠教师。
- **完整训练目标（仍锁）。** `L_total = L_task(y, ŷ_S) + λ1 · w_i · L_geo(A_T, A_S) + λ2 · w_i · L_sem(F_sem^T, F_sem^S) + λ3 · L_orth(F_geo^S, F_sem^S) + λ4 · L_aux_ing(y_ing, ŷ_ing)`。原稿建议的初始权重是 `λ1 = 1.0`、`λ2 = 0.5`、`λ3 = 0.1`、`λ4 = 0.2`，可按梯度量级微调。这组权重不是停止规则，也不提前变成第一阶段的写法。第一阶段的 B3 不加 `w_i`，不加 `L_orth`。

t-SNE、Grad-CAM 与难例分析，以及推理效率对比（参数量、FLOPs、延迟，对照测试时跑深度估计的方法），放到第二或第三阶段。第一阶段不要求。

## 代码编写边界

本文件 squash 合并进 `digi-nutri`，并且这一合并发生在 Triste 本人批准之后，下一次代码改动才可以开始。不得从这份尚未合并的拉取请求开工。代理说用户已经同意，不算批准。在那之前不训练。写代码以官方方案页和本文件为准，不要把 HTML 附件当成另一份真源。

下一次代码只实现第一阶段：几何教师、成分教师，以及同骨干、同预算的 B1、B2a、B2b、B3。教师先训到收敛再冻结。

- 几何教师：RGB + 官方真值深度，双流，跨模态通道-空间注意力融合，多尺度 `F_geo^T`。深度归一化到 [0, 1]，无效空洞用均值或中值填充。
- 成分教师：冻结的预训练文本编码器，默认 CLIP-Text；食材名称编成菜品级语义向量，交叉注意力调制视觉特征，得到 `F_sem^T`。默认不加克重加权。若加，同时实现只用名称的教师消融。不把成分级热量或宏量当作教师输入。
- B1：只有 `L_task`。
- B2a：`L_task` + `L_geo`。`L_geo` 是空间亲和力，用 `A_T` 与 `A_S`，不用像素级特征 L2。
- B2b：`L_task` + `L_sem` + `L_aux`。`L_aux` 用 BCE，测试时去掉。
- B3：`L_task` + `L_geo` + `L_sem` + `L_aux`。两个蒸馏项接到同一套学生特征上，融合用拼接或相加。不加解耦，不加门控，不加 `w_i`。

学生是纯 RGB 主干加多任务回归头。可以按上面的推荐起点起跑。那些超参不是停止规则。

不写 DSD，不写 `L_orth`，不写 GOFF，不写 `w_i`，不写仍锁的 `L_total`。不写第二阶段，不写第三阶段。不把 t-SNE、Grad-CAM、难例分析或推理效率对比写进这次改动。不对 `main` 开拉取请求，不把实验代码落到 `main`。
