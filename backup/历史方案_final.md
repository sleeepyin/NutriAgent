# 历史方案记录

> 记录 MM-CFA (多模态共形食物分析) 项目所有尝试过的方案、当前状态、瓶颈原因和失败原因。

---

## 一、行得通的方案（可继续优化）

### 1. 权重预测：ResNet18 + EfficientNet-B0 Ensemble

| 项目 | 详情 |
|------|------|
| **方案** | 双模型集成，4通道RGB-D输入(224×224)，log-MSE loss（模型预测原始值，loss = MSE(log(pred), log(target))） |
| **训练** | 80/20划分，2608训练样本，weights=None，100 epochs，CosineAnnealingLR，轻量增强(flip + color jitter) |
| **当前效果** | PMAE=9.44%±1.05%（10次试验，50/20/30划分），最低7.13% |
| **文件** | `train_deep_v2.py`, `models/deep_weight_*.pth` |

**可优化方向：**
- 增加训练样本（当前2608张，可考虑数据增强生成更多样本）
- 尝试更深骨干网络（ResNet50, EfficientNet-B3等），但需注意4通道适配
- 尝试SE注意力机制或ViT类架构
- 增加深度通道的预处理（如深度归一化、边缘检测）

### 3. k-NN 混合密度预测

| 项目 | 详情 |
|------|------|
| **方案** | 从权重模型提取特征，用cosine相似度检索训练集中k=5个最近邻，取密度均值，与模型预测按α=0.85混合 |
| **当前效果** | Cal PMAE 23.9%→22.7%（1.2pp提升），Fat/Carb/Protein提升0.4-0.9pp |
| **文件** | `test_100_samples.py` (NutrientPredictor类) |

**可优化方向：**
- 动态α（根据检索置信度自适应调整混合比例）
- 更大k值范围搜索 + 距离加权（而非简单平均）
- 多模态特征融合（加入YOLO掩码特征、颜色直方图等）

### 6. ✅ NEW GBML：梯度平衡多任务损失 (v4)

| 项目 | 详情 |
|------|------|
| **方案** | 可学习不确定性权重 `L = Σᵢ exp(-sᵢ)·MSEᵢ + sᵢ`，初始化 `sᵢ = ½log(MSEᵢ首batch)` 归一化各任务初始梯度。解决 v2 中 cal loss(0.06) 对 fat loss(0.001) 的 60 倍梯度失衡 |
| **训练** | 与 v2 完全一致（架构/epochs/LR/WD/无增强），仅换损失函数 |
| **效果** | 密度 MAE 四项全部下降，R² 四项全部上升：Fat PMAE 39.1→37.3(−1.8pp)，Protein 37.2→36.0(−1.2pp)，Cal −0.2pp，Carbs +0.2pp(噪声级)。叠加 k-NN(α=0.75) 后全测试集均值 PMAE 34.8%→33.6% |
| **文件** | `train_nutrient_v4.py`, `models/density_*_v4.pth` |
| **机理** | homoscedastic uncertainty weighting (Kendall et al.) + loss-scale init。log_s 单独参数组不加 weight_decay，clamp [-6,6] |

**可优化方向：**
- GBML + 更长训练（当前100ep，GBML 权重后期才收敛稳定）
- 把 GBML 思路迁移到 conformal 校准集的 multi-quantile 学习

### 7. ✅ NEW AEC-S Nutrient：营养素分层共形区间 (2026-08-20)

| 项目 | 详情 |
|------|------|
| **方案** | 把 AEC-S 从重量扩展到 4 个营养素（Cal/Fat/Carb/Prot）：每营养素独立构建 5 候选区间（Split / Norm / LogSplit / Propagate / MondrianW），按预测重量分 bin 做 Dirichlet 凸组合集成 + 贝叶斯收缩（τ=30），最后分 bin conformal 重标定（AEC-S2m-N，复刻重量版获胜配方） |
| **协议** | 严格 hold-out：生产管线（v2 权重 + v4 GBML 密度 + kNN α=0.60）训练于 2608，X_test(652) 对半切 cal(326)/eval(326)，10 trials，α=0.10 |
| **效果** | 全营养素 Coverage 89.7–90.6%（目标 90%）；归一化 Winkler **2.42** vs 最强基线 MondrianW 2.50（−3.2%）、Split 2.74（−12%） |
| **文件** | `nutrient_conformal_final.py`，`models/nutrient_conformal_calibrator.pkl`（部署校准器），已整合进 `test_100_samples_final.py` |

**各营养素详细（AEC-S2m-N, 10 trials 均值）：**

| 营养素 | Coverage | Rel-Width | Winkler | 备注 |
|--------|----------|-----------|---------|------|
| Calories | 90.5% | 95.6% | 392 | 区间约 ±98 kcal（均值216） |
| Fat | 90.6% | 166.3% | 31 | 密度误差主导，区间必然宽 |
| Carbs | 89.7% | 152.1% | 70 | |
| Protein | 90.5% | 151.8% | 38 | |

**关键发现：**
- **Propagate 单独使用严重欠覆盖**（Fat 63.7%）：重量区间 × 密度点估计只覆盖重量误差，密度误差（PMAE 33-37%）才是营养素不确定性的主导项；但作为集成候选项仍有贡献（提供重量尺度结构）
- **LogSplit 在小值营养素上区间爆炸**（rel-width 246-359%）：log 空间 q 在近零区域不稳定
- **重标定必要**：AEC-S-N（无重标定）Fat 覆盖仅 88.6%，分 bin 重标定（S2m）恢复到 90.6%
- 获胜规则：所有营养素 cov≥89.5%（覆盖承诺优先于宽度），AEC-S2m-N 以 nWinkler 2.42 胜出

**2026-08-20 v2 优化尝试（3 项，全部证伪，记录于 `nutrient_conformal_final.py`）：**

| 尝试 | 单阶段结果 | 两阶段结果 | 结论 |
|------|-----------|-----------|------|
| [1] AsymNorm 非对称候选（误差右偏） | nWinkler 2.58, cov 88.7% ✗ | — | 单独使用欠覆盖 |
| [2] DisagreeD 模型-检索分歧定标 | nWinkler 2.80, cov 88.3% ✗ | — | 分歧信号弱于相对误差 |
| [3] 营养素分位分层 7S | nWinkler 2.38, cov 89.0% ✗ | 2.43, cov 89.7% | 见下 |
| [4] 两阶段校准（权重/q 分离） | — | 5W2: 2.46/cov90.5% | 覆盖修复但更宽 |

- **核心发现（double-dipping）**：单阶段中 Dirichlet 权重与重标定 q 共用同一段 cal，权重过拟合 → q 偏小 → eval 欠覆盖。观测规律：**容量越大欠覆盖越重**（5W 89.7% > 7W 89.4% > 7S 89.0%）
- 两阶段校准（cal 对半分 A/B，权重学于 A、q 算于 B）成功恢复覆盖（7S: 89.0→89.7%），但宽度回升，**诚实协议下无一配置超过 v1 的 2.42**
- **结论：新候选在单阶段下的"收益"（2.38-2.40）本质是欠覆盖换来的虚假收益；v1 的 5 候选 + 重量分层已是这些信号的信息上限**。部署保持 AEC-S2m-N（5候选, 单阶段）不变

**2026-08-20 CQR 尝试（第 5 项，证伪，详见"失败18"）：** 训练 12 输出分位密度模型（pinball+GBML，τ=0.1/0.5/0.9）后共形化，6 变体最优 CQR-hyb-b nWinkler 2.55 vs AEC 2.42 → **仍败**。分位 spread 估计在 2608 样本上欠拟合（raw-cov 34.7% vs 期望 80%），自适应宽度信号太噪。AEC-S2m-N 保持部署

## 二、瓶颈方案（能跑但效果受限）

### 瓶颈1：权重模型在更小训练集上表现差

| 项目 | 详情 |
|------|------|
| **现象** | 用50/20/30划分（1629训练样本）重训时，PMAE=293%（vs 原80/20划分的9.44%） |
| **瓶颈原因** | **训练样本量不足**。原80/20划分有2608个训练样本，50/20/30划分只有1629个（减少38%）。深度模型（ResNet18+EfficientNet）对数据量敏感，1629个样本不足以充分训练4通道输入模型。 |
| **影响** | 无法在论文标准的50/20/30划分上端到端重训，只能依赖80/20预训练模型 + 50/20/30校准/测试 |

---

### 瓶颈2：密度预测精度不足

| 项目 | 详情 |
|------|------|
| **现象** | 营养素预测中，Fat/Carb/Protein的PMAE高达34-39%，远高于Calories的22.7% |
| **瓶颈原因** | **(1) 密度值极小且稀疏**：fat_g均值仅0.042，carb_g均值0.108，模型难以学习微小差异。(2) **密度变异性大**：同一重量区间的食物密度差异巨大（如200g的沙拉 vs 200g的牛排），仅靠图像特征难以区分。(3) **4输出共享骨干**：4个营养素密度共享同一特征提取器，互相干扰。 |
| **影响** | 营养素预测上限受密度模型精度限制，当前Oracle上限：Cal PMAE≈7.5% |

---

### 瓶颈3：小样本重量区间（0-50g, 500g+）

| 项目 | 详情 |
|------|------|
| **现象** | 0-50g区间 PMAE≈91%，500g+区间样本极少（<30个），AEC-S权重不稳定 |
| **瓶颈原因** | **(1) 数据不均衡**：Nutrition5K数据集中0-50g和500g+样本极少。(2) **极端值预测困难**：0-50g区间相对误差被放大（5g误差即10% PMAE）。(3) **Bayesian Shrinkage治标不治本**：τ=30的收缩可以稳定权重，但无法提升基预测器在这些区间的精度。 |
| **影响** | AEC-S在这些区间的区间宽度远超其他区间（0-50g: 42g宽度 vs 76g均值） |

---

### 瓶颈4：营养素预测在单次测试集上波动大

| 项目 | 详情 |
|------|------|
| **现象** | 论文报告Cal PMAE=12.6%（10次试验均值），但100样本测试显示22.7% |
| **瓶颈原因** | **(1) 划分差异**：论文10次试验用50/20/30划分做conformal实验，权重模型在80/20预训练。单次100样本测试直接用80/20测试集，划分不同导致PMAE偏高。(2) **样本选择偏差**：100随机样本可能恰好包含困难样本。(3) **10次试验平滑效应**：多次试验平均能消除单次划分的偏差。 |
| **影响** | 单次测试结果不能直接与论文10次试验均值对比 |

## 三、行不通的方案（已证伪）

### 失败1：IMAGENET预训练权重用于4通道输入

| 项目 | 详情 |
|------|------|
| **尝试** | 用 `weights='IMAGENET1K_V1'` 初始化ResNet18/EfficientNet-B0，conv1从3通道扩展为4通道 |
| **结果** | 权重模型PMAE=144-4098%（预测完全崩溃），或产生NaN |
| **失败原因** | **4通道RGB-D与3通道RGB的分布差异过大**。IMAGENET预训练的特征提取器（边缘检测、纹理识别等）针对RGB图像优化，深度通道的加入破坏了低层特征的分布，导致后续层激活值异常。即使conv1权重做了均值复制，深层特征仍无法适配。 |
| **教训** | 4通道模型必须从头训练（weights=None），或使用RGB-D专用的预训练方法 |

---

### 失败2：数据增强用于密度模型

| 项目 | 详情 |
|------|------|
| **尝试** | 在密度模型训练中加入flip + color jitter + rotation增强 |
| **结果** | 密度MAE从0.42恶化到0.69（+64%），所有营养素指标变差 |
| **失败原因** | **密度预测依赖精细的视觉特征**（纹理、颜色、透明度），这些特征与食物的营养成分高度相关。Flip和color jitter破坏了这些精细特征，导致模型学习到错误的密度-视觉关联。相比之下，重量预测对增强的鲁棒性更高（重量主要依赖体积/面积特征）。 |
| **教训** | 密度预测应使用保守的增强策略（或无增强），避免破坏营养成分相关的视觉线索 |

---

### 失败3：log1p-MSE loss 直接在模型输出上计算

| 项目 | 详情 |
|------|------|
| **尝试** | 模型预测原始密度值，loss = MSE(log1p(pred), log1p(target)) |
| **结果** | 密度模型效果比直接预测log1p值差（MAE 0.42 vs 0.71） |
| **失败原因** | **梯度缩小效应**：`dL/dθ = 2*(log1p(pred)-log1p(target)) × 1/(1+pred) × d(pred)/dθ`。因子1/(1+pred)在pred较大时显著缩小梯度（如cal_g均值1.29时，梯度缩小到44%）。而直接预测log1p值时，`dL/dθ = 2*(pred-log1p(target)) × d(pred)/dθ`，无梯度缩小。 |
| **教训** | 对于需要log-space训练的回归任务，应该让模型直接预测log-space值，而非在loss中做log变换 |

---

### 失败4：EfficientNet-B0 用于密度预测

| 项目 | 详情 |
|------|------|
| **尝试** | 用EfficientNet-B0替代ResNet18做密度预测 |
| **结果** | ValMAE=17-19（完全发散），无法收敛 |
| **失败原因** | **EfficientNet的depthwise separable convolution对4通道输入不稳定**。第1层conv从3通道扩展到4通道后，depthwise conv的通道间交互模式被破坏。ResNet18的标准卷积对此更鲁棒。 |
| **教训** | 4通道输入场景下，ResNet18比EfficientNet-B0更稳定。如需使用EfficientNet，需要特殊的4通道初始化策略 |

---

### 失败5：150 epochs + 增强训练（过拟合）

| 项目 | 详情 |
|------|------|
| **尝试** | 将训练从100 epochs增加到150 epochs，同时加入数据增强 |
| **结果** | 密度模型效果更差，VlLoss上升（过拟合），测试集效果下降 |
| **失败原因** | **训练集有限（2608样本）**，增加epochs + 增强导致模型在训练集上过拟合，泛化能力下降。100 epochs + 无增强是当前数据量下的最优配置。 |
| **教训** | 在小数据集上，更多的epochs不一定更好。需要配合验证集早停 |

---

### 失败6：50/20/30划分上重训权重模型

| 项目 | 详情 |
|------|------|
| **尝试** | 用论文标准的50/20/30划分（1629训练样本）端到端重训权重模型 |
| **结果** | PMAE=293%（完全不可用） |
| **失败原因** | **训练样本不足**（见瓶颈1）。1629样本不足以训练4通道ResNet18+EfficientNet-B0集成。对比原80/20划分的2608样本，减少了38%的训练数据，模型无法学到有效的特征表示。 |
| **教训** | 当前模型必须用80/20划分训练，50/20/30划分仅用于conformal calibration和测试 |

### 失败7：Per-Nutrient 独立建模 + CNCR + TTA (v3)

| 项目 | 详情 |
|------|------|
| **尝试** | 拆分为4个独立ResNet18（各预测一个营养素密度），CNCR (λ=0.1) 训练时约束 Atwater 一致性，推理时TTA（4 views: flip + 亮度±5%） |
| **结果** | Cal PMAE 45.1%（vs v2的24.3%），Fat 45.8%（vs 37.2%），Carbs 59.7%（vs 41.4%），Protein 44.3%（vs 38.2%）。全面劣于v2。 |
| **失败原因** | **(1) 独立建模去掉多任务正则化**：4输出模型共享backbone本身就是一种正则化，拆成4个独立模型后每个只有1/4的监督信号，2608样本下严重过拟合（Fat loss从0.0010升到0.0029）。(2) **TTA亮度破坏了深度通道**：亮度增强(±5%)也作用在depth通道上，深度值被扭曲。(3) **CNCR λ=0.1过高**：压过MSE主损失，模型为满足Atwater约束牺牲了精度。 |
| **教训** | 小数据集(2608样本)上，多任务共享backbone的正则化效果不可替代。独立建模只适用于大数据场景。 |

### 失败8：4-Output + CNCR 弱约束 (v3b, λ=0.01)

### 失败12：Huber-in-log 损失 + TSR 硬样本加权微调 (v5)

| 项目 | 详情 |
|------|------|
| **尝试** | 重量模型 v5：Huber(log1p 空间, δ=0.3) 替代 log-MSE 实现损失-指标对齐 + TSR 硬样本微调（log 残差 >0.7 的 2.5x 权重） + SGDR 3×40ep snapshot ensemble |

### 已证伪方向（不应再尝试）

- ❌ **CNCR 训练损失**：任何 λ 下都破坏 Fat 预测（3次实验确认）
- ❌ **APC Atwater 后验校正**：β 单调恶化，高误差组合校正低误差预测必败（Atwater 方向整体关闭）
- ❌ **CA-kNN 动态 α**：检索距离与密度误差弱相关，无置信度信息可用（静态 α=0.60 已采纳）
- ❌ **Per-Nutrient 独立建模**：小数据集上缺少多任务正则化，严重过拟合
- ❌ **TTA（无训练增强）**：训练时无增强，推理时 TTA 输入分布偏移
- ❌ **IMAGENET 预训练权重**：4通道 RGB-D 与 3通道 RGB 分布不兼容
- ❌ **数据增强用于密度模型**：破坏营养成分相关的精细视觉特征
- ❌ **EfficientNet-B0 用于密度**：depthwise conv 对 4通道输入不稳定
- ❌ **Huber-in-log 损失（v5）**：log 空间 δ=0.3 对大残差样本梯度压扁 15 倍，大重量系统性低估（bias −40~−82g）
- ❌ **TSR 硬样本加权微调（v5）**：Huber 梯度被压扁后，加权 2.5x 反而放大偏差（view3 bias −82g）
- ❌ **Snapshot Ensemble 权重（v5b）**：v2 配方 + SGDR 2×50ep，4 个快照全部坍塌（PMAE 62-117%），SGDR 在 4 通道小数据集上不稳定
- ❌ **逆频率加权（v6）**：0-50g 占比 <5% 导致权重爆炸（~25x），val PMAE 30000%；尺度歧义无法靠加权解决
- ❌ **100g+ 过滤从零训练（v7）**：1844 样本数据饥饿，回归到均值 42.69%；EffNet 冷启动发散
- ❌ **在已见数据上微调（v7b）**：微调集被 v2 训练集 100% 污染，记忆覆盖泛化（6794%）；必须用 v2 未见过的新数据
- ❌ **k-NN 检索预测重量**：视觉相似≠质量相似（25-29% vs v2 的 18.4%）；检索增强只适用于内在属性（密度），不适用于尺度依赖量（重量）
- ❌ **flip-TTA（v2 权重模型）**：18.42%→19.66%，v2 训练时虽有 flip 增强但预测分布仍偏移（v7b 实验附带发现）

### 过程中抓到的两个数据 bug（诚实性记录）

1. **NV-Real metadata 多实例覆盖 bug**：同类多实例列为重复列（dish 21: salad-chicken-strip ×3），phase0 的 `items[t]=v` 覆盖而非求和 → 29% (766/2614) 裁剪 GT 被低估。修复=求和（251 菜 `sum(各列)==total_food_weight` 校验和全部自洽实锤）。GT median 44→84g。
2. **任务错位（首版 Phase 2 作废）**：N5K cache 真实语义 = y=`total_mass_g` 整盘总重 + 最大 mask 抠背景 + pad 20px（train_deep_weight.py 的 precompute_crops）。首版拿整盘模型评"单食材裁剪+带背景"= 694% 无效数字。修复=协议对齐重写（phase2b：union mask → pad 20px → 抠背景 → 菜品总重 GT）→ 103.7% 有效。
3. **附带发现——v2 4ch 训练脚本 augment bug**：`clamp(rgb,0,1)` 作用在 ImageNet 归一化数据（-2.1~2.6）上，训练时 RGB 大半被压 0、评测用原值 → 训练/评测分布错配。4ch 模型因深度通道不被 clamp 而存活（22% 是"带伤"成绩，数字偏保守）；3ch 全通道被毁 → 首训爆炸（PMAE 110%/28394%）。修复=去 clamp（温度抖动在归一化空间同样成立）。**可选后续**：用修复版 augment 重训 4ch 可能再涨一点，为保证与论文基线可比暂不动。

## Q1 升级实验 22：多域联合训练（2026-08-24，双赢结果）

**动机**：Limitations #6 从"认怂"升级为"量化解法"——域差能不能被多域数据买回？

|---|---|---|

**结论**：
- 联合训练几乎完全买回域差（77.4%→23.9%），源域零代价（31.4%→31.5%），甚至略优于纯目标域训练
