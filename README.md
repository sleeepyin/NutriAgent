# NutriAgent archive index

This branch is a lightweight catalog. It does not contain historical trees.

Every preserved branch tip is a tag `snapshot/<exact-branch-name>`. Full SHAs and one-line descriptions, grouped by line of work, are in [ARCHIVE.md](ARCHIVE.md).

To recover one exact tree, check out that tag:

```
git fetch origin tag snapshot/icdl
git checkout snapshot/icdl
```

`snapshot/digi-nutri` stays at the pre-#97 tip `3c0488a242041ac7d8da6567c0f350c9e9aba63a`. `snapshot/main` is the empty commit `d43cb084eba7693a45c114dfdf06b258611463f4`. `snapshot/cursor/same-split-dpf-swin-8e07` is the same-split ruler record `a89be031c6be18f8e8df8568d64e0e907ebb1897`, not a pass line.
