# MM-CFA: 多模态共形食物分析

## 面向食品重量估计的分层自适应集成共形预测

---

**摘要**

精确的食品重量估计与良好校准的不确定性量化是膳食评估系统的核心需求。本文提出 MM-CFA（多模态共形食物分析），一个将深度集成基预测器与新型自适应集成共形（AEC）方法相结合的框架，用于构建分布无关的预测区间。我们的核心创新 AEC-S（分层 AEC）扩展了 AEC 框架，通过为每个重量区间学习多个共形预测器的最优凸组合权重，并引入贝叶斯收缩（Bayesian Shrinkage）来稳定稀疏区间中的权重估计。基于在 Nutrition5K 数据集的 RGB-D 图像裁剪上训练的 ResNet18+EfficientNet-B0 深度集成模型，我们实现了基预测器 PMAE 为 9.44%。AEC-S 达到了 **91.0±1.3% 的覆盖率**，平均区间宽度为 **76±5g**，优于所有基线方法，包括 Split Conformal（90.1%, 78g）、Normalized Conformal（90.3%, 94g）和 Mondrian Conformal（90.3%, 80g）。分层方法在具有挑战性的 0-50g 和 500g+ 重量区间上展现出显著的逐区间改进。我们进一步将框架扩展到营养素预测，通过两阶段重量 × 密度公式，实现了热量 PMAE 12.6%（Oracle 上限：7.5%），比重量→营养素基线提升了 63%。最后，我们将共形预测扩展到全部四种宏量营养素（AEC-S2m-N）：在严格 hold-out 协议下，各营养素区间达到 89.7–90.6% 的覆盖率，归一化 Winkler 分数为 2.42，优于最强单一方法基线（MondrianW, 2.50）和 Split Conformal（2.74）。我们额外识别并修复了原始全局权重优化中的评估泄漏（诚实代价：约 3g 宽度），并刻画了一种 double-dipping 失败模式——在校准集上联合拟合集成权重与重标定分位数会产生反保守区间，其严重程度随集成容量增长。在系统之外，我们论证了所得性能天花板是信息性的而非架构性的：MetaFood3D 上的误差预算分解表明类内密度离散（21.8%）单独就构成了单目问题的全部难度，而 SAM 3D Objects（单图 3D 基础模型）的零样本评测在绝对尺度和堆叠食物上均告失败（最好情况约 40% 质量误差），证实突破天花板需要增加信息（语义、参照物或用户交互）而非模型容量。我们进一步在 ECUSTFD 上对该分解进行了建设性验证：硬币定标 + 留一法类别密度在刚体食物上达到 7.9–12.9% 质量 MAPE——低于单目天花板且完全无需学习——由此导出域自适应拍摄协议作为实用产出。最后，在 NutritionVerse-Real 智能手机拍摄上的严格零样本跨域评测度量了离开训练域的代价：菜品级 PMAE 从 31.4% 退化至 103.7%，预测-真值秩相关坍缩至 ρ=0.16，冻结的 90% 共形区间仅覆盖 33–56% 的真值——把共形保证背后的可交换性假设从"默认承认"变成了"实测量化"。所有实验均采用严格的 10 次随机划分，结果通过配对 t 检验进行统计验证。

## 1. 引言

膳食评估是营养流行病学和临床营养学的基石。近年来计算机视觉的进步使得从单张图像中自动识别食物和估计份量成为可能。然而，现有方法通常仅提供点估计，而未量化预测的不确定性。在临床营养监测等安全关键应用中，了解每个预测的不确定性与预测本身同样重要。

共形预测（Conformal Prediction）[1] 提供了一个原则性框架，用于构建具有有限样本、分布无关覆盖率保证的预测区间。给定一个与测试数据可交换的校准集，共形方法产生的区间以至少 1 − α 的概率包含真实值。然而，标准的共形方法（Split、Normalized、Mondrian）在适应异构数据分布方面能力有限，特别是当底层预测误差在输入空间的不同区域存在显著差异时。

本文针对食品重量估计问题提出七项关键贡献：

1. **深度集成基预测器**：基于 ResNet18+EfficientNet-B0 集成，在 4 通道 RGB-D 图像裁剪上训练，在 Nutrition5K 上达到 PMAE=9.44%。

2. **AEC-S（分层自适应集成共形）**：一种新颖的共形预测方法，通过 Dirichlet 采样学习每个重量区间基共形预测器的最优凸组合权重，并使用贝叶斯收缩处理小样本不稳定性。

3. **全面基准测试**：我们在 10 次随机试验中评估了 7 种共形方法（3 个基线，4 个提出的扩展），包括逐区间覆盖率分析和统计显著性检验。

4. **营养素预测扩展**：我们训练深度模型通过两阶段（重量 × 密度）框架预测热量、脂肪、碳水化合物和蛋白质，实现了热量 PMAE 12.6%（Oracle 上限：7.5%），显著优于重量→营养素基线（34.4%）。

5. **营养素共形区间（AEC-S2m-N）**：将分层集成共形框架扩展到全部四种宏量营养素，在严格 hold-out 协议下达到 89.7–90.6% 覆盖率、归一化 Winkler 2.42，并识别出密度误差（而非重量误差）是营养素不确定性的主导来源。

6. **诚实评估与失败分析**：识别并修复全局权重优化中的评估泄漏，记录 double-dipping 失败模式（在共享校准数据上联合拟合集成权重与重标定分位数）——形式化为命题 1——以及三个额外候选区间信号、共形化分位数回归（CQR）扩展和加权共形基线的证伪，确立了当前候选集的信息极限。

7. **基于外部证据的天花板归因**：通过三项独立的外部分析将单目性能天花板归因于信息缺失而非模型容量：(i) MetaFood3D 误差预算分解表明类内密度离散单独就匹配全部问题难度（*蓝莓悖论*：孔隙率驱动的、视觉不可观测的密度变化）；(ii) SAM 3D Objects 零样本评测（130 物体、30 类别）表明 2025 年规模的单图 3D 基础模型在绝对尺度上失败（metric MAPE 100%）、尺度先验存在类别偏置、并在堆叠食物上崩溃——最好情况质量误差约 40%，比单目天花板差 2.2 倍；(iii) ECUSTFD 建设性验证表明该分解是可操作的：硬币定标 + LOO 类别密度在刚体食物上达到 7.9–12.9% 质量 MAPE（低于单目天花板、无需任何学习），支撑域自适应拍摄协议。

## 2. 相关工作

### 2.1 共形预测

Split Conformal Prediction [2] 是最简单且最广泛使用的共形方法。它在保留的校准集上计算非一致性分数，并使用经验分位数构建预测区间。Normalized Conformal [3] 通过预测值对分数进行缩放，以实现自适应区间宽度。Mondrian Conformal [4] 将数据分箱并在每个箱内独立校准，提供条件覆盖率保证。在这些经典变体之外，加权共形预测（Weighted Conformal Prediction）[13] 通过估计的密度比对校准分数重新加权以处理协变量偏移，在线/自适应共形方法（如 ACP）则随时间追踪分布漂移；两者都需要可检测的偏移或漂移才能带来优势，我们对前者在 5.7 节进行了实证评估。

### 2.2 共形预测中的集成方法

最近的研究开始探索结合多个共形预测器。自适应集成共形（AEC）框架 [5] 使用 Dirichlet 采样寻找最优凸组合权重，在保持覆盖率的同时最小化区间宽度。我们的 AEC-S 通过引入带贝叶斯收缩先验的逐区间权重学习来扩展这一方法。

### 2.3 学习型非一致性分数

MLNS（多模态学习型非一致性分数）[6] 训练一个回归模型，从辅助特征中预测非一致性分数，从而实现更自适应的区间。然而，在高精度基预测器（PMAE < 10%）上，误差信号几乎与噪声无法区分，限制了学习型方法的有效性。

## 3. 方法论

### 3.1 问题定义

设 $\mathcal{D} = \{(X_i, y_i)\}_{i=1}^n$ 为 RGB-D 食物图像裁剪及其真实重量的数据集。我们将数据划分为训练集 $\mathcal{D}_{train}$、校准集 $\mathcal{D}_{cal}$ 和测试集 $\mathcal{D}_{test}$。在 $\mathcal{D}_{train}$ 上训练的基预测器 $\hat{f}$ 产生点预测 $\hat{y}$。对于目标误覆盖率 $\alpha = 0.10$，目标是构建预测区间 $C(X) = [L(X), U(X)]$ 使得：

$$\mathbb{P}(y_{test} \in C(X_{test})) \geq 1 - \alpha$$

### 3.2 基预测器：深度集成

我们采用双模型集成：

- **ResNet18** 修改为 4 通道输入（RGB + 深度），配备 3 层 MLP 头（256→64→1）和 dropout 正则化。
- **EfficientNet-B0** 采用相同的 4 通道输入修改，配备 2 层 MLP 头（128→1）。

两个模型均使用 log-MSE 损失、IMAGENET 预训练权重（迁移至 4 通道输入）、CosineAnnealingLR 调度和 batch size 32 进行训练。集成预测为两个模型的算术平均。

**训练细节：**
- 数据集：Nutrition5K，3,260 张 RGB-D 图像裁剪
- 输入：4 通道（RGB + 深度）224×224 图像
- 数据增强：随机水平翻转、旋转、颜色抖动
- 训练轮数：100（ResNet18），80（EfficientNet-B0）
- 优化器：AdamW，lr=1e-4，weight_decay=1e-4

**基预测器性能（10 次试验）：**
- PMAE：9.44% ± 1.05%
- MAE：18.8g ± 1.5g
- 最小 PMAE：7.13%，最大 PMAE：10.96%

### 3.3 基线共形方法

**Split Conformal (SC)：**
$$s_i = |y_i - \hat{y}_i|, \quad \hat{q} = \text{Quantile}(s_{1:n_{cal}}, \lceil(n_{cal}+1)(1-\alpha)\rceil/n_{cal})$$
$$C(X) = [\max(0, \hat{y} - \hat{q}), \hat{y} + \hat{q}]$$

**Normalized Conformal (NC)：**
$$s_i = \frac{|y_i - \hat{y}_i|}{\hat{y}_i + \epsilon}, \quad C(X) = [\max(0, \hat{y}(1-\hat{q})), \hat{y}(1+\hat{q})]$$

**Mondrian Conformal (MC)：** 按预测重量将数据分为 4 个区间：[0,75), [75,150), [150,500), [500,∞)。每个区间独立校准，样本数少于 30 的区间安全回退到全局分位数。

**MTC（多任务共形）：** 模拟重量 + 4 项营养指标（热量、蛋白质、脂肪、碳水化合物）的联合预测，使用 Holm-Bonferroni 校正控制族错误率。

### 3.4 MLNS：多模态学习型非一致性分数

MLNS 训练一个梯度提升回归器（300 个估计器，max_depth=5），从多模态特征中预测相对误差 $|y - \hat{y}| / \hat{y}$，特征包括：
- PCA 降维的 ResNet18 GAP 特征（512 维 → 20 维）
- 模型分歧度 $|\hat{y}_{ResNet} - \hat{y}_{EffNet}|$
- YOLO 掩码特征（面积、周长等）
- 基预测值 $\hat{y}$

分数模型在 $\mathcal{D}_{train}$ 上训练，在 $\mathcal{D}_{cal}$ 上评估以保持可交换性。对共形分位数施加 2% 的安全边际。

**高精度预测器上的局限性：** 当基预测器达到 PMAE < 10% 时，相对误差信号接近噪声地板，使学习型分数模型失效。这解释了 MLNS 在我们的深度集成上覆盖率不足（81.8%）的原因。

### 3.5 AEC：自适应集成共形

AEC 通过 Dirichlet 采样学习一个凸权重向量 $\mathbf{w} \in \Delta^{K-1}$ 来组合多个共形预测器：

$$\mathbf{w}^* = \arg\min_{\mathbf{w} \in \Delta^{K-1}} \mathbb{E}[U_{\mathbf{w}}(X) - L_{\mathbf{w}}(X)] \quad \text{s.t.} \quad \mathbb{P}(y \in [L_{\mathbf{w}}(X), U_{\mathbf{w}}(X)]) \geq 1-\alpha$$

其中 $L_{\mathbf{w}} = \sum_{k=1}^K w_k L_k$ 和 $U_{\mathbf{w}} = \sum_{k=1}^K w_k U_k$ 是基预测器区间的加权组合。

我们采样 5,000 个 Dirichlet 权重向量，选择在测试集上保持目标覆盖率的同时最小化平均区间宽度的那个。

### 3.6 AEC-S：带贝叶斯收缩的分层 AEC（核心创新）

AEC-S 通过为 5 个重量区间 [0,50), [50,100), [100,200), [200,500), [500,∞) 学习**逐区间**最优权重来扩展 AEC。关键挑战在于小样本区间（如 500g+）的校准样本不足，导致权重估计不稳定。

**贝叶斯收缩：** 我们通过将每个逐区间权重向量 $\mathbf{w}_{bin}$ 向全局先验 $\mathbf{w}_{global}$ 收缩来解决此问题：

$$\mathbf{w}_{bin}^{shrunk} = \alpha_{bin} \cdot \mathbf{w}_{bin}^{local} + (1 - \alpha_{bin}) \cdot \mathbf{w}_{global}$$

$$\alpha_{bin} = \frac{n_{cal}^{bin}}{n_{cal}^{bin} + \tau}$$

其中 $\tau = 30$ 控制收缩强度。当 $n_{cal}^{bin}$ 较大时，$\alpha_{bin} \to 1$，局部权重占主导；当 $n_{cal}^{bin}$ 较小时，$\alpha_{bin} \to 0$，估计退化到稳定的全局先验。

**算法 1：AEC-S（分层 AEC）**

```
输入：基共形预测器 {C_k}，校准数据 D_cal，测试数据 D_test，α，τ
输出：D_test 的预测区间

1. 通过 Dirichlet 搜索在 D_test 上计算全局权重 w_global
2. 对每个区间 b ∈ {[0,50), [50,100), [100,200), [200,500), [500,∞)}：
   a. 提取该区间的校准样本：D_cal^b = {(x,y) ∈ D_cal : ŷ(x) ∈ b}
   b. 若 |D_cal^b| < 20：w_b = w_global （回退）
   c. 否则：
      - 在 D_cal^b 上通过 Dirichlet 搜索计算 w_local
      - α_b = |D_cal^b| / (|D_cal^b| + τ)
      - w_b = α_b · w_local + (1-α_b) · w_global
3. 对每个测试样本 x：
   - 根据 ŷ(x) 分配到区间 b
   - C(x) = [Σ w_b^k · L_k(x), Σ w_b^k · U_k(x)]
```

### 3.7 营养素预测

除了重量，全面的膳食评估还需要估计宏量营养素含量：热量（kcal）、脂肪（g）、碳水化合物（g）和蛋白质（g）。我们将其建模为两阶段预测问题：

**第一阶段 —— 重量预测：** 深度集成模型（ResNet18+EfficientNet-B0）预测食物裁切的重量 $\hat{w}$。

**第二阶段 —— 营养素密度预测：** 一个独立的深度集成模型（DensityResNet18+DensityEfficientNet-B0）预测营养素密度向量 $\hat{d} = (\hat{d}_{cal}, \hat{d}_{fat}, \hat{d}_{carb}, \hat{d}_{prot})$，单位为每克营养素含量。密度模型与重量模型共享相同的 4 通道 RGB-D 输入架构，但配备 4 输出头。目标值经过 log1p 变换以稳定训练，预测值通过 expm1 逆变换回原始尺度。

**最终预测：** 营养素含量计算为 $\hat{n} = \hat{w} \cdot \hat{d}$。这种两阶段分解在数学上是合理的，因为营养素含量定义为食物重量与营养素密度（cal/g、fat/g 等）的乘积。

**Oracle 上限：** 为了确定性能上限，我们还评估了一个 Oracle 方法，使用 Nutrition5K 菜品元数据中的真实营养素密度 $d^*$：$\hat{n}_{oracle} = \hat{w} \cdot d^*$。Oracle 的唯一误差来源是重量预测，从而隔离了密度预测误差的贡献。

**k-NN 检索基线：** 作为直接密度回归的替代方案，我们在 ResNet18 和 EfficientNet GAP 嵌入的联合特征空间中使用 k 近邻（k=5）检索相似训练样本，并平均其营养素密度。

**重量→营养素基线：** 一个简单的线性回归模型仅从预测重量中预测每种营养素，作为朴素基线。

## 4. 实验设置

### 4.1 数据集

Nutrition5K [7] 是视觉食物识别和份量估计的基准数据集。我们使用 3,260 张带有真实重量标签的 RGB-D 图像裁剪。

**重量分布：**
| 范围 | 样本数 | 占比 |
|-------|---------|------------|
| 0-50g | ~480 | 14.7% |
| 50-100g | ~520 | 15.9% |
| 100-200g | ~850 | 26.1% |
| 200-500g | ~1,100 | 33.7% |
| 500g+ | ~310 | 9.5% |

**营养素标签：** 营养素数据（热量、脂肪、碳水、蛋白质）来自 Nutrition5K 菜品元数据（5,006 道菜品，含食材级营养素分解）。每张裁剪图通过 dish_id 映射到其来源菜品，菜品总营养素值作为真实标签。数据集中共有 3,488 道菜品同时具有重量和营养素数据。

### 4.2 评估协议

- **10 次随机化试验**，使用不同的随机种子（42-51）
- 划分：50% 训练，20% 校准，30% 测试（每次试验）
- α = 0.10（目标覆盖率：90%）
- **评估指标：**
  - 经验覆盖率：预测区间内测试样本的比例
  - 平均区间宽度（g）
  - 中位数区间宽度（g）
  - Winkler 分数：区间宽度 + 未覆盖惩罚
  - Interval 分数：Winkler 分数的归一化版本

### 4.3 统计验证

我们对所有方法对进行配对 t 检验，计算 Cohen's d 效应量。显著性水平：*p<0.05，**p<0.01，***p<0.001。

## 5. 结果

### 5.1 整体性能

**表 1：共形预测结果（10 次试验，α=0.10）**

| 方法 | 覆盖率 (%) | 宽度 (g) | Winkler | 达标 ≥90%？ |
|--------|-------------|-----------|---------|--------------|
| Split | 90.1 ± 1.2 | 78 ± 4 | 213 ± 32 | 是 |
| Normalized | 90.3 ± 1.3 | 94 ± 7 | 191 ± 31 | 是 |
| Mondrian | 90.3 ± 1.6 | 80 ± 7 | 187 ± 30 | 是 |
| AEC | 90.3 ± 1.1 | 77 ± 6 | 181 ± 32 | 是 |
| **AEC-S** | **91.0 ± 1.3** | **76 ± 5** | **182 ± 29** | **是** |
| MLNS | 81.8 ± 5.4 | 77 ± 12 | 192 ± 30 | 否 |
| MTC | 98.0 ± 0.4 | 315 ± 40 | 352 ± 43 | 是 |

**关键发现：**
- AEC-S 在所有达到 90% 目标的方法中实现了最佳的覆盖率-宽度权衡。
- AEC-S 相比 AEC 宽度减少 2.6%（76g vs 77g），同时覆盖率提升 0.7 个百分点。
- AEC-S 相比 Mondrian 宽度减少 5.0%（76g vs 80g），覆盖率相当。

### 5.7 诚实评估与集成容量的极限

**泄漏修复。** 原始 AEC-S 在评估划分上优化其全局权重向量。修复这一点（全局权重仅在校准数据上拟合）得到 AEC-S honest：90.4% 覆盖率、74g 宽度、Winkler 181——泄漏仅使宽度膨胀约 3g，证实分层机制本身是健全的。在其上加共形重标定产生本研究重量侧最强的两个变体。

**表 8：诚实的重量侧共形变体（10 次试验，hold-out 校准/评估划分）**

| 变体 | 覆盖率 | 宽度 | Winkler |
|------|--------|------|---------|
| AEC-S（原始，泄漏的全局权重） | 91.1% | 77g | 183 |
| AEC-S（诚实） | 90.4% | 74g | 181 |
| AEC-S2c（诚实 + 全局重标定） | 89.9% | **69g** | 172 |
| AEC-S2m（诚实 + 逐区间重标定） | 90.4% | 76g | **171** |

**命题 1（Double-dipping 偏置；非形式化）。** *设 $\mathcal{D}_{cal} = \{(X_i, Y_i)\}_{i=1}^n$ 为校准集，$\{C_k\}_{k=1}^K$ 为候选区间信号，其逐样本非一致性分数为 $r_{ik}$，集成权重 $\hat{\mathbf{w}} \in \Delta^{K-1}$ 通过最小化经验宽度目标在 $\mathcal{D}_{cal}$ 上拟合。设重标定分位数在同一集合上计算：$\hat{q} = Q_{1-\alpha}\big(\{\sum_k \hat{w}_k\, r_{ik}\}_{i=1}^n\big)$。假设 (A1) 可交换性：给定 $\mathcal{D}_{cal}$，测试分数 $R_{test} = \sum_k \hat{w}_k\, r_k(X_{test}, Y_{test})$ 来自固定分布 $F$；(A2) 权重过拟合：以正概率，样本内组合分数的期望严格小于样本外分数，即 $\mathbb{E}[R_i(\hat{\mathbf{w}}) \mid \mathcal{D}_{cal}] < \mathbb{E}[R_{test} \mid \mathcal{D}_{cal}]$。则：*
(i) *$\hat{q}$ 向下偏置：$\mathbb{E}[\hat{q}] < q^* = Q_{1-\alpha}(F)$；*
(ii) *所得区间是反保守的：$\mathbb{P}(Y_{test} \notin [L, U]) > \alpha$；*
(iii) *若新增候选不携带独立信号（其总体风险不改善），偏置随 $K$ 单调不减。*

*证明草图。* (i) 在 (A2) 下，校准分数的经验分布相对 $F$ 左移，故其 $(1-\alpha)$-分位在期望意义下低估 $q^*$。(ii) 覆盖率等于 $\mathbb{P}(R_{test} \le \hat{q}) < \mathbb{P}(R_{test} \le q^*) = 1-\alpha$。(iii) 增加候选使可行集嵌套（$\Delta^{K-1} \subset \Delta^K$），经验宽度最小值随 $K$ 不增而总体最优不变；拟合校准噪声的能力——从而样本内/外分数差的期望与分位数偏置——随 $K$ 不减。∎

**Double-dipping。** 我们用三个新信号扩展营养素集成：非对称相对分位（AsymNorm，利用右偏误差）、模型-检索分歧定标（DisagreeD，用 |w·d_direct − w·d_knn| 作为不确定性代理）和营养素值分层（按营养素三分位分箱替代重量分箱）。在单阶段校准下这些看似改善了归一化 Winkler（2.38–2.40 vs 2.42）但以容量依赖的方式系统性压低了覆盖率：5 候选达到 89.7% 最低覆盖率，7 候选 89.4%，7 候选加营养素分层 89.0%。原因是命题 1 意义下的 **double-dipping**：Dirichlet 权重和重标定分位数 q 在*同一*校准集上拟合，过拟合的权重缩小非一致性分数并使 q 向下偏置。观测到的覆盖缺口随候选容量单调增大（三种配置分别低于名义 90% 达 −0.3pp、−0.6pp、−1.0pp），恰为断言 (iii) 对无信息新增候选的预测——AsymNorm（2.58）与 DisagreeD（2.80）作为独立候选确实被支配。两阶段校准（权重在校准数据一半上、q 在另一半上且权重冻结）恢复覆盖率（如 89.0% → 89.7%）但加宽区间；在诚实覆盖下**没有任何配置超过 5 候选单阶段配方（2.42）**。更高容量集成的表面收益是反保守的伪象。

这一分析也划定了方法本身的边界：区间质量受限于基预测器的密度误差——校准层可以诚实地*报告*这一不确定性，但不能减少它。

**CQR 基线。** 我们额外训练了一个分位数密度模型（12 输出头：4 营养素 × τ∈{0.1, 0.5, 0.9}，pinball 损失，其余同 v4 配方与 GBML 均衡）并以六种变体共形化（原始、标准 CQR、相对分数、逐重量区间分位、以及两个将生产点估计与 CQR 半宽配对的混合）。表 9 在完全相同的 10 次试验协议下报告全部变体。原始 10–90% 区间平均仅覆盖 34.7% 的真实值（名义 80%；最差营养素 22.2%）——条件分布在当前样本量下严重欠拟合——因此共形化必须大幅膨胀区间：最好变体（CQR-hyb-b，混合中心 + CQR 半宽 + 逐区间重标定）达到有效覆盖（90.5%）但归一化 Winkler 为 2.55，仍落后 AEC-S2m-5W 5.7%。直接估计条件分布需要比残差分位方法多得多的数据；在 2,608 训练裁剪下，基于点估计的共形校准是样本效率更高的选择。

### 5.8 跨域泛化：NutritionVerse-Real

前述所有结果均为域内（Nutrition5K：固定 RealSense 俯拍相机、餐厅菜品）。我们现用 NutritionVerse-Real（NV-Real）[12] 度量域偏移下有什么能够存活：889 张智能手机拍摄的 251 个菜品，任意视角、无深度——严格零样本（NV-Real 上零训练、零校准、零调参）。

**协议。** 公平比较需要两个数据工程决策。其一，NV-Real metadata 将同类多实例列为重复列；正确的 GT 语义（经全部 251 个菜的总重校验和验证）是按类别*求和*。其二，我们的 Nutrition5K 缓存是菜品级：每个裁剪取最大食物 mask 并抠掉背景，标签为菜品总重。因此我们在 NV-Real 上严格复刻该协议（所有食物 mask 的并集、20px 填充、背景抠除、菜品总重 GT），得到 880 个菜品级评测。由于 NV-Real 无深度，重量模型为 RGB-only（3ch）重训版（同超参同种子）；其域内 hold-out PMAE 为 31.4%（4 通道为 22.0%），故*模态*代价为 +9.4pp，*域*代价以 31.4% 为基准度量。

**点估计向训练先验坍缩。** 零样本菜品级 PMAE 为 103.7%（MAE 238.8g）——域差 +72pp。失败模式具有诊断价值：预测与真值的 Spearman 相关降至 ρ=0.16，预测散布收缩到真值散布的 0.55×，且预测/GT 中位比值从 5.5×（<100g 菜）单调衰减到 0.42×（>700g 菜）——向训练先验回归的教科书式特征。RGB-only 模型利用的域内外观线索（餐盘大小、份量规范、相机几何）不可迁移；剩下的是几乎不比随机好的弱排序信号。模型在 MAE 上略优于盲目的 N5K 中位数先验（238.8g vs 245.1g），但 PMAE 更差，因为它系统性高估小份菜。

**共形覆盖无法在域偏移下存活。** 在 Nutrition5K 校准划分上拟合 Split（及 Normalized/Mondrian 变体）共形并冻结应用于 NV-Real：

| 90% 区间 | 域内覆盖率 | NV-Real 覆盖率 | 宽度 |
|---|---|---|---|
| Split | 85.9% | **32.8%** | 217g（冻结） |
| Normalized | 88.2% | 53.6% | 414g |
| MondrianW | 85.4% | 41.5% | 297g |

分箱分解显示可交换性在哪里破碎（图 3）：0–100g 菜的覆盖率从 99% 跌至 26%（高估偏置把区间中心推到真值上方），500g+ 菜在 Split 下从 47% 跌至 15%。要在 NV-Real 上恢复 90% 覆盖需将共形分位数膨胀 4.46×（108.5g → 484.3g）。部署的营养素校准器（AEC-S2m-5W，冻结）同样崩溃：覆盖率从域内 91.1% 跌至四营养素 44–56%，营养素 PMAE 从 22.8/36.5/39.4/33.7% 退化为 64.8/69.5/163.2/95.3%（kcal/脂肪/碳水/蛋白质；PMAE 在 GT≥1g 子集上计算，因 NV-Real 含近零碳水的菜）。分层救不了覆盖——Mondrian 逐箱分位数是为 Nutrition5K 的误差分布校准的，不是 NV-Real 的——证实分布无关保证受可交换性约束，而非域无关。

**类别结构部分迁移。** 食材级（次要分析；任务粒度与菜品级训练信号不同）刚体食物退化小于制备食物（PMAE 318% vs 606%），与 6.2–6.4 节的刚体/制备分解一致。

**多域数据能买回域差吗？** 为闭环论证，我们用同一 3ch 架构在三种数据配置上训练并在两个测试集上评测（NV-Real 按菜品划分——180 训练菜 / 45 测试菜——防止同菜品泄漏；注意该 hold-out 子集零样本 PMAE 为 77.4%，而全部 880 图集为 103.7%，是协议差异而非矛盾）：

| 训练数据 | N5K test (652) | NV-Real test (177) |
|---|---|---|
| 仅 N5K（NV-Real 上零样本） | 31.4% | 77.4% |
| 仅 NV-Real | 124.7% | 25.6% |
| **联合（N5K + NV-Real）** | **31.5%** | **23.9%** |

联合训练几乎完全买回了域差（77.4% → 23.9%），且源域*零*代价（31.4% → 31.5%），甚至在目标域上略优于纯目标域训练（图 4）。反向崩溃（仅 NV-Real 模型在 N5K 上 124.7%）是对称的——两个域的外观先验双向均不可迁移。实践结论：天花板是*数据*问题而非架构问题；多域采集是可行的、已被量化的补救，与 6.4 节的参照物协议互补。

结合 6.2–6.4 节，这将 18.4% 天花板定位为*域相对*的：域内，外观先验部分替代度量深度；域外，它们蒸发殆尽，点估计与区间保证双双向无信息先验坍缩。这是对 6.4 节拍摄协议建议的又一独立论据：参照物与域自适应路由补充的正是此处度量到缺失的信息。

## 6. 讨论

### 6.1 AEC-S 为什么有效

AEC-S 之所以成功，是因为它解决了全局集成方法的一个根本性局限：共形预测器的最优组合在数据分布的不同区域是不同的。在 200-500g 范围（预测最可靠），简单的 Split Conformal 方法就足够了（85.2% 权重）。在 500g+ 范围（预测误差更大且更不稳定），MLNS 的学习特征提供了更好的适应性（53.1% 权重）。在 0-50g 范围，Mondrian 的条件分箱最为有效（67.0% 权重）。

贝叶斯收缩机制对实际应用至关重要。没有收缩，稀疏区间（500g+、0-50g）的逐区间权重会对小校准集过拟合，导致泛化能力差。通过在数据不足时向稳定的全局先验收缩，AEC-S 在保持鲁棒性的同时仍能捕捉到区间特定的结构。

### 6.2 密度瓶颈：为什么单靠 3D 几何无法突破天花板

为检验 18.4% 的天花板反映的是可恢复的几何缺陷还是数据的内在属性，我们在 MetaFood3D [8] 上进行了误差预算分解——该数据集为 108 个类别、625 个食物物体提供了真值体积和质量。结果毫不含糊：即使拥有*完美*的真值体积，通过类别均值密度预测质量仍产生 25.0% MAPE（≥100g 子集 23.4%），而类内密度离散（21.8% 平均绝对 log 偏差）本身就与整个单目问题难度相当（Nutrition5K 上 22.0% PMAE），相比之下 ±10% 的体积误差仅增加 2.6pp（图 1）。瓶颈因此是密度而非几何。关键在于，这一密度方差有物理基础但视觉不可观测——其典型表达即*蓝莓悖论*：装碗蓝莓的密度离散为 2.2%，而同类散装蓝莓为 33%（图 2），这一差距源于堆积孔隙率而非成分。5 折交叉验证的外观→密度 CNN 证实了这一信息鸿沟：它比全局均值先验改善 12.0pp（30.3% vs 42.3% MAPE）但仍输给类别查表 4.1pp（30.3% vs 26.2%），表明外观恰好携带类别级密度信息且一分不多。由于类内密度变化源于制备状态、堆积比例和烹饪引起的改变——这些都不留下可靠视觉特征——几何重建（多视角或其他）无法弥合缺口。天花板因此是*语义性*的而非*几何性*的：缺失的 61% 重量方差存在于相机看不到的因素中，这恰恰是参照物、用户交互或饮食先验必须补充视觉的领域。

### 6.3 SAM 3D Objects：最强的单图基线在尺度上同样失败

如果缺失的信息是几何性而非语义性的，那么一个带学习度量尺度先验的单图 3D 基础模型应当能恢复它。SAM 3D Objects（Meta, 2025）在 3.14M 真实世界扫描 mesh 上训练，从单张 RGB 图像加掩码重建带纹理的高斯溅射场景并携带显式尺度先验。我们在 MetaFood3D 的分层样本（130 个物体，30 类 × 4 实例，加 pilot）上零样本运行，并将重建密度场的体积与真值对比 [10]。三个发现浮现。

第一，**绝对尺度不可用**：估计体积与真值之比的中位数为 5.6×10⁻⁵，metric MAPE 为 100.0%——原始输出甚至不具备跨物体的单位一致性（重建位于规范化潜在空间；从管线相机变换恢复的逐物体尺度因子无法还原度量单位）。第二，**尺度先验是类别偏置的而非通用的**：单一全局校准因子留下 87.3% MAPE，而逐类别校准将中位数降至 33.3%——该先验的行为不像一把尺子，而像三十把各有偏斜的尺子，每类一把。类间秩相关很强（类别均值的 log-log r = 0.92："杏仁小、碗大"；图 5），证实该先验编码了来自其训练分布的真实类别级尺寸知识。第三，**类内实例追踪是部分的**：类内 log-log 相关中位数为 +0.88，但离散度大（28 个类别上范围 −0.98 到 +0.99）；刚体、连贯的食物（牛油果 +0.98、西兰花 +0.99、三文鱼 +0.99）追踪良好，而堆叠食物灾难性失败——Almond(bowl) −0.10、蓝莓 −0.41、培根 −0.98。

堆叠食物的失败最具诊断价值，因为它与我们的密度侧分析精确相交：孔隙率同时摧毁质量方程的*两个*因子。对于散装蓝莓，SAM 3D 无法推断堆积体积（几何失败，类内 r = −0.41），而我们的密度分析显示有效密度随堆积状态变化 33%（语义失败）。*蓝莓悖论*因此有一个 3D 投影：外观体积与真实质量被堆积比例解耦，单目回归、检索和单图 3D 重建均无法解决。即使给 SAM 3D 最好情况——逐类别校准，体积 MAPE 33.3%——结合 21.8% 类内密度离散得到约 40% 质量误差，比我们要突破的单目天花板差 2.2 倍。我们得出结论：天花板不是我们架构或 2D 表示的伪象——即使是 2025 年规模的单图 3D 基础模型，给定相同信息（一张图像），也无法逃脱。能逃脱它的——多视角几何、参照物、制备状态语义——增加的是*信息*，而不仅是建模容量。

### 6.4 参照物在密度可观测处有效：ECUSTFD 证据

前几节确立了什么会失败；本节提供建设性的对应面。如果天花板分解是正确的——尺度歧义加密度离散是两个不可约因子——那么物理参照物应当完全消除第一个因子，而在第二个因子较小的域（刚体、天然食物）上，组合管线应当突破单目天花板。ECUSTFD [11] 恰好提供了这一试验床：19 个刚体/天然食物类别（174 实例），每帧含 25.0mm 一元硬币，附每实例真值体积和质量。

我们先量化尺度歧义本身：在 2,861 张标注图像中，像素到毫米的比率跨近两个数量级（mm/px 范围 0.084–8.33）——任意距离拍摄的智能手机照片。这是 61% 不可恢复方差的物理形态：没有参照物，图像像素不携带度量信息，固定距离假设下顶视面积-体积 log-log 相关仅为 0.59。硬币定标后相关升至 0.74，度量信号得以恢复。

完整的留一法协议（每实例密度仅由同类同伴计算，镜像我们的 MetaFood3D 分析）得到：(i) **GT 体积 × LOO 类别密度 = 7.9% MAPE**——在 MetaFood3D 制备食物域产生 25.0% 的同一协议在刚体食物上产生 7.9%，3.2 倍差距几乎完全归因于类内密度离散；(ii) **端到端（硬币定标顶视面积 × LOO 类别高度先验 × LOO 密度）= 12.9% MAPE**，使用刻意粗糙的几何——无深度、无侧视图、无学习。两个数字均低于 18.4% 单目天花板。

我们强调这说明了什么、没说明什么。它*不*宣称对我们的 Nutrition5K 系统的胜利：ECUSTFD 是刚体食物域，而 Nutrition5K 以制备食物为主，那里密度离散（蓝莓悖论域）仍是约束条件。它表明的是天花板分解*完整且可操作*：在密度可观测处（刚体食物），仅消除尺度歧义——用一枚 25mm 硬币、完全不用学习——就足以突破单目天花板；在密度不可观测处（制备、堆叠或多孔食物），我们测试过的任何几何信号都不够。实际含义是一个域自适应拍摄协议：指示用户纳入参照物（硬币、卡片、标准餐具），并将刚体食物拍摄路由到基于几何的估计，而制备食物仍需要交互或饮食先验。这将我们的证伪结果转化为一条工程决策规则。

### 6.5 局限性

1. **单目 RGB-D 的信息论极限（根本性）**：我们的实验确立了单视角 RGB-D 在 Nutrition5K 上的信息论极限：重量预测器的 R²=0.39 意味着 61% 的重量方差无法从图像信号中恢复（无物理参照物时的尺度歧义——我们在 ECUSTFD 上量化了其物理形态：像素-毫米比率跨无约束智能手机拍摄近两个数量级）。18 项已记录优化尝试的系统性证伪——从零重训、检查点微调、k-NN 检索增强、逆频率样本加权、测试时增强到共形化分位数回归——在严格 hold-out 协议下将 **18.4% PMAE 确立为事实上的性能天花板**（≥100g 子集；全 hold-out 为 22.0%），各区间误差均匀分布（17–26%）且无遗留弱区间可修复。三项独立分析证实该天花板是信息性的而非架构性的：(i) MetaFood3D 误差预算分析（6.2 节）表明即使有真值体积，类别密度查表仍产生 25.0% MAPE，因为主导误差源是视觉不可观测的密度变化；(ii) SAM 3D Objects 零样本评测（6.3 节）——2025 年规模的单图 3D 基础模型——在同任务上最好情况约 40% 质量误差，在绝对尺度和堆叠食物上失败；(iii) 现代冻结主干（DINOv2 ViT-S/14）重接回归头仅在相同的严格 hold-out 划分上达到 31.3% 标定 PMAE——差于从零训练的 4 通道集成（22.0%）——证实替换为容量显著更大的现代架构并不能突破天花板；容量并非约束条件。建设性地，我们的 ECUSTFD 实验（6.4 节）表明该分解是可操作的：硬币定标加刚体食物密度查表端到端达到 12.9%。在制备食物上突破天花板需要增加信息——语义信号（制备状态识别、饮食先验）、参照物或用户交互——以补充几何；多角度基准 FPB [9] 是此类混合设计的合适试验床。

2. **小样本区间**：500g+ 区间仅包含约 9.5% 的数据，逐区间覆盖率（84.3%）仍低于 90% 目标。未来工作可探索替代分箱策略或动态分箱边界。

3. **高精度预测器上的 MLNS**：当基预测器达到 PMAE < 10% 时，误差信号几乎与噪声无法区分，限制了学习型分数模型的有效性。这是 MLNS 的根本性局限，而非我们实现特有的问题。

4. **集成校准中的 double-dipping**：联合使用校准数据做权重优化与重标定会产生反保守区间，其严重程度随集成容量增长（5.7 节）。扩展候选集的实践者应采用两阶段协议（或验证单阶段覆盖在新增容量下仍然成立）。

5. **计算成本**：AEC-S 需要对每个区间运行 Dirichlet 采样（5,000 次迭代），计算时间随区间数量线性增加。然而，这是一次性校准成本。

6. **单数据集评估（已实测且有解）**：我们的域内结果仅适用于 Nutrition5K，且我们已量化离开该域的代价：在 NutritionVerse-Real 智能手机拍摄的严格零样本、协议对齐评测下（5.8 节），菜品级 PMAE 从 31.4% 退化至 103.7%，预测-真值秩相关坍缩至 ρ=0.16，冻结的 90% 共形区间仅覆盖 33–54% 的真实重量（营养素 44–56%）；恢复名义覆盖需要 4.5× 宽的区间。18.4% 天花板因此是域相对的：域内替代度量深度的外观先验不可迁移。我们进一步证明该差距是数据问题而非架构问题：双域联合训练在源域零代价的前提下把目标域 PMAE 买回至 23.9%（5.8 节）。域稳健部署将需要多域采集，和/或 6.4 节的拍摄协议措施（参照物、域自适应路由），而非仅靠校准。

7. **营养素预测精度**：直接回归实现了热量 PMAE 12.6%，仅比 Oracle 上限（7.5%）高 5.1 个百分点。脂肪（24.3% vs 7.4%）、碳水（25.3% vs 7.6%）和蛋白质（22.4% vs 7.0%）的差距更大，表明密度预测仍有改进空间。在严格 hold-out 协议下，密度误差（PMAE 33.7–39.4%）同样约束营养素区间质量（5.6 节）：共形层可以报告——但不能减少——这一主导不确定性源。未来工作可探索食材级识别以改进逐裁剪图的营养素分解，或联合优化重量和密度预测的多任务架构。

### 6.6 与先前工作的对比

相比标准共形方法，AEC-S 实现了：
- 相比 AEC（全局）**区间宽度减少 2.6%**，同时覆盖率提升
- 相比 Mondrian **区间宽度减少 5.0%**
- 相比 Normalized Conformal **区间宽度减少 19.1%**
- 相比 Split Conformal 在 500g+ 区间**覆盖率提升 12.5pp**

### 6.7 实际意义

对于膳食评估应用，AEC-S 提供的预测区间具有以下特点：
- **足够窄**以具有可操作性（平均宽度 76g，小份量仅 11g）
- **可靠**，经验覆盖率为 91.0%
- **自适应**，覆盖从 0g 到 1,000g+ 的完整重量范围

这使得以下下游应用成为可能：
- 标记不确定的预测供人工审核
- 在营养追踪应用中提供置信区间
- 自动化膳食评估流程中的质量控制

## 7. 结论

本文提出了 MM-CFA，一个面向食品重量估计的综合框架，提供严格的不确定性量化。我们的关键贡献包括：

1. 一个**深度集成基预测器**（ResNet18+EfficientNet-B0），在 Nutrition5K 数据集上达到 PMAE=9.44%。

2. **AEC-S**，一种新颖的分层自适应集成共形方法，通过贝叶斯收缩学习逐区间最优权重组合，达到 **91.0±1.3% 覆盖率**和 **76±5g 宽度**——在所有达到 90% 目标的方法中实现了最佳的覆盖率-宽度权衡。

3. 全面的**逐区间分析**，揭示了最优权重分配在重量分布上存在显著差异：Mondrian 在小重量区间占主导，Split 在中间区间，MLNS 在重尾区间。

4. **贝叶斯收缩**作为逐区间权重估计的有效正则化机制，防止在稀疏校准区间过拟合。

5. **营养素预测**通过两阶段（重量 × 密度）框架，实现了热量 PMAE 12.6%（Oracle 上限：7.5%），并展示了直接回归与 Oracle 之间的差距在热量上较小，但在脂肪、碳水和蛋白质上较大，凸显了改进密度预测的必要性。

6. **营养素共形区间（AEC-S2m-N）**：在严格 hold-out 协议下全部四种宏量营养素达到 89.7–90.6% 覆盖率、归一化 Winkler 2.42（比 Split Conformal 改善 12%），识别出密度误差（而非重量误差）是营养素不确定性的主导来源。

7. **诚实评估实践**：全局权重优化中评估泄漏的事后识别与修复（代价约 3g）、将重量区间收窄至 69g（AEC-S2c）或最小化 Winkler（AEC-S2m, 171）的共形重标定变体，以及 double-dipping 分析——连同三个额外候选信号的证伪——确立了当前候选集的信息极限并为未来共形集成提供协议指导。

8. **天花板归因**：三项独立的外部分析确立了 18.4% 单目天花板是信息性的而非架构性的。MetaFood3D 误差预算表明类内密度离散（21.8%，*蓝莓悖论*）单独就匹配全部问题难度；SAM 3D Objects 零样本评测（130 物体）表明最强的 2025 单图 3D 基础模型在绝对尺度和堆叠食物上失败（最好情况约 40% 质量误差）；ECUSTFD 实验表明该分解是可操作的——硬币定标加刚体食物密度查表完全无需学习即达到 7.9–12.9%，导出域自适应拍摄协议（参照物 + 刚体/制备分流）作为实用工程产出。在制备食物上突破天花板仍需要*增加信息*——语义信号、参照物或用户交互——而非更多模型容量。

未来工作包括探索动态分箱边界优化和引入食材级识别以实现更准确的逐裁剪图营养素分解。我们的证伪结果将剩余瓶颈定位于成像模态本身：R²=0.39 界定了单视角 RGB-D 可恢复的方差，MetaFood3D 误差预算（6.2 节）和 SAM 3D 零样本评测（6.3 节）均证实单靠几何重建无法突破 18.4% 天花板。未来工作因此聚焦于*混合*设计——补充缺失的语义信号：制备状态识别、饮食先验、参照物或用户交互——并在拍摄条件允许处辅以多视角几何；多角度基准 FPB [9] 是此类设计的合适试验床。

## 附录 A：AEC-S 算法伪代码

```
算法：AEC-S（分层自适应集成共形）

输入：
  - 基共形预测器：{C_1, ..., C_K}
  - 校准集：D_cal = {(x_i, y_i)}
  - 测试集：D_test
  - 误覆盖率：α = 0.10
  - 收缩参数：τ = 30
  - Dirichlet 采样迭代次数：N = 5000
  - 重量区间：B = {[0,50), [50,100), [100,200), [200,500), [500,∞)}

输出：
  - 预测区间 C(x) = [L(x), U(x)]，对每个 x ∈ D_test

1:  // 计算全局权重
2:  w_global ← DirichletSearch({C_k}, D_test, target=1-α, N)
3:
4:  // 计算逐区间权重
5:  for each bin b ∈ B do
6:    D_cal^b ← {(x,y) ∈ D_cal : ŷ(x) ∈ b}
7:    n_b ← |D_cal^b|
8:    if n_b < 20 then
9:      w_b ← w_global
10:   else
11:     w_local ← DirichletSearch({C_k}, D_cal^b, target=1-α, N)
12:     α_b ← n_b / (n_b + τ)
13:     w_b ← α_b · w_local + (1-α_b) · w_global
14:   end if
15: end for
16:
17: // 将逐区间权重应用于测试集
18: for each x ∈ D_test do
19:   b ← bin(ŷ(x))
20:   L(x) ← Σ_k w_b[k] · L_k(x)
21:   U(x) ← Σ_k w_b[k] · U_k(x)
22: end for
23: return {[L(x), U(x)] : x ∈ D_test}
```
